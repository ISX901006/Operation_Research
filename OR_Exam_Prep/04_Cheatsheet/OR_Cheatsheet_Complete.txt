TOPIC 1：LP 建模（Model Formulation）
==================================================

1. 題型辨識
  • 題目長相：一段文字情境，要求 "define decision variables"、"objective function"、"constraints"、"complete model"、"formulate as an LP"。
  • 關鍵字與對應寫法
      "maximize profit / minimize cost"       → 目標函數
      "available / at most / capacity"       → ≤
      "at least / requirement / minimum"     → ≥
      "exactly / fixed contract"             → =
  • 數學結構：每種資源或需求對應一條約束；每種產品或活動對應一個變數。
  • 與圖解法題的差別：建模題只問「寫出模型」，不一定要求解。若題目還要求解，且只有 2 個變數，就接 TOPIC 2。

2. 解題邏輯
  • 要解決的問題：把文字翻譯成數學，後面所有演算法都以這個模型為輸入。
  • 核心想法：決策 = 變數；好壞 = 目標；限制 = 約束。〔L1 p26–28、p33〕
  • 關鍵判斷
      ① 變數的單位是什麼？
      ② 每條約束是 ≤、≥ 還是 =？
      ③ 有沒有隱含的限制（例如非負）？
  • LP 四個假設：proportionality、additivity、divisibility、certainty。〔L1 p34–36〕
      只要題目出現量大折扣、交互作用（xᵢxⱼ）、必須是整數、參數不確定，就代表某個假設被違反。（T1 Q7）

3. 解題 SOP
  Step 1　定義變數：「Let xⱼ = …（單位、時間範圍）」，每個產品或活動一個變數。
  Step 2　寫目標：Z = Σ（每單位利潤或成本）× xⱼ，並標明 max 或 min。
  Step 3　寫約束：每種資源或需求寫一列。
          Σ（每單位用量）× xⱼ（≤ / ≥ / =）可用量或需求量
          每條約束後面用括號註明意義。
  Step 4　寫上 x ≥ 0（除非題目允許負值）。
  Step 5　把 Step 2–4 組合成完整模型。
  Step 6　代一個簡單點檢查：單位是否一致、方向是否合理。

4. 重要公式
  • 一般最佳化模型〔L1 p20〕：
      max / min f(x)
      s.t. gᵢ(x) ≤ 0；hⱼ(x) = 0；x ∈ S
    當 f、g、h 都是線性函數，且 S 是 x ≥ 0 時，就是 LP。
  • LP 標準寫法：
      max Z = c₁x₁ + … + cₙxₙ
      s.t. aᵢ₁x₁ + … + aᵢₙxₙ ≤ bᵢ　(i = 1…m)
           x₁, …, xₙ ≥ 0

5. 完整實戰案例（T1 Q1）
  【題目】
    書架：每個需木工 3 小時、塗裝 1 小時，利潤 $50。
    椅子：每張需木工 1 小時、塗裝 1 小時，利潤 $30。
    每週可用：木工 24 小時、塗裝 10 小時。
    求每週生產量，使利潤最大。
  【題目辨識】有 maximize profit、有可用時數上限 → 建模題，最大化，約束為 ≤。
  【解法選擇】直接套 TOPIC 1 的 SOP；只有 2 個變數，所以可以再用 TOPIC 2 求解。
  【初始設定】
    x₁ = 每週書架數，x₂ = 每週椅子數。
  【逐步計算】
    目標：每個書架賺 50、每張椅子賺 30
          → Max Z = 50x₁ + 30x₂
    木工：每個書架用 3 小時、每張椅子用 1 小時，總共不超過 24
          → 3x₁ + x₂ ≤ 24
    塗裝：同理
          → x₁ + x₂ ≤ 10
    非負：x₁, x₂ ≥ 0
  【完整模型】
    Maximize Z = 50x₁ + 30x₂
    Subject to:
      3x₁ + x₂ ≤ 24　（木工）
      x₁ + x₂ ≤ 10　（塗裝）
      x₁, x₂ ≥ 0
  【延伸求解〔補充〕】
    頂點：(0,0) → 0；(8,0) → 400；(7,3) → 440；(0,10) → 300
    (7,3) 是兩條約束的交點：3x₁ + x₂ = 24 與 x₁ + x₂ = 10 相減得 2x₁ = 14。
    最優解 (7,3)，Z = 440。
  【答案驗證】
    3·7 + 3 = 24 ≤ 24 ✓
    7 + 3 = 10 ≤ 10 ✓
    單位都是「小時」，一致 ✓
  【常見錯誤】
    • 把約束寫成「每種產品一列」。正確是「每種資源一列」。
    • 漏寫 x ≥ 0。
  【通用規則】欄 = 產品（變數），列 = 資源（約束）；表格裡的數字直接就是係數矩陣。

  補充案例
    T1 Q2：min 成本、約束為 ≥（營養需求）。
    T1 Q3：「每天固定 100 公升」要寫 x₁ + x₂ = 100，不是 ≤ 100。

6. 常見錯誤與答案驗證
  • 「恰好 / 固定」寫成 ≤（T1 Q3）。
  • 「至少」寫成 ≤。
  • 驗證方法：代入一個已知可行的點；逐條檢查每條約束兩邊的單位。

7. 考試速查
  • 每個變數都要寫單位；每條約束都要註明意義。
  • 一句話：變數是決策，目標是好壞，約束是每種資源各一列，最後補上 x ≥ 0。

TOPIC 2：二維圖解法與模型狀態判斷
==================================================

1. 題型辨識
  • 題目長相：只有 2 個變數，問 "solve graphically" 或 "determine whether the LP is infeasible / unbounded / has multiple optima"。
  • 與 TOPIC 4 的差別：圖解法是比較所有頂點；TOPIC 4 是從一個角落出發，只看它的 edges。

2. 解題邏輯
  • 等值線 c₁x₁ + c₂x₂ = k 互相平行；k 改變時，整條線平移。
  • 可行域是凸多邊形。等值線往「變好」的方向推，最後碰到的點（或邊）就是最優解。〔L1 p56–58〕
  • 若 LP 可行且有界，最好的頂點一定是最優解。〔L1 p50、L2 p9〕

3. 解題 SOP
  Step 1　畫每條約束的邊界線（取兩個截距），再代入原點判斷可行的一側。
  Step 2　找出可行域的所有頂點：把每兩條相交的邊界線聯立求解。
  Step 3　列表計算每個頂點的 Z。
  Step 4　判斷狀態
          • 唯一最優：只有一個頂點最好。
          • 多重最優：有兩個相鄰頂點同為最好，且等值線與它們之間的邊平行 → 整條邊都是最優解。
          • unbounded：可行域沿著「變好」的方向無界 → 寫出射線 x(t)，並證明 Z(t) → ∞。
          • infeasible：各約束的可行側沒有交集 → 寫出代數矛盾。
  Step 5　寫出最優解、最優值，以及一句狀態說明。

4. 重要公式
  • 等值線斜率：−c₁/c₂。
  • 若某條邊界 a₁x₁ + a₂x₂ = b 的斜率 −a₁/a₂ 等於 −c₁/c₂，且這條邊在變好的方向上，就會有多重最優解。

5. 完整實戰案例（T1 Q8 / Q9 / Q10 / Q11）
  【題目 A，T1 Q8】Max Z = 3x + 2y，s.t. x + y ≤ 8，2x + y ≤ 12，x, y ≥ 0。
  【題目辨識】只有 2 個變數 → 圖解法。
  【逐步計算】
    頂點：
      (0,0)
      (6,0)：2x + y = 12 與 y = 0 的交點
      (4,4)：x + y = 8 與 2x + y = 12 相減得 x = 4，再得 y = 4
      (0,8)：x + y = 8 與 x = 0 的交點
    各頂點的 Z = 3x + 2y：
      (0,0) → 0；(6,0) → 18；(4,4) → 20；(0,8) → 16
  【答案】最優解 (4,4)，Z = 20。
  【驗證】4 + 4 = 8 ≤ 8 ✓；8 + 4 = 12 ≤ 12 ✓

  【題目 B，T1 Q9】可行域同上，目標改成 Max x + y。
    頂點 (4,4) 和 (0,8) 的值都是 8；等值線 x + y = k 與邊界 x + y = 8 平行。
    → 連接 (4,4) 與 (0,8) 的整條邊都是最優解，Z = 8。

  【題目 C，T1 Q10】Max x + 2y，s.t. −x + y ≤ 4，x − 2y ≤ 2，x, y ≥ 0。
    射線 (t, t+4)，t ≥ 0：
      −t + (t+4) = 4 ≤ 4 ✓
      t − 2(t+4) = −t − 8 ≤ 2 ✓
    Z = t + 2(t+4) = 3t + 8 → ∞，所以 unbounded。

  【題目 D，T1 Q11】Max x + y，s.t. x + 2y ≤ 6，2x + y ≤ 6，x + y ≥ 8，x, y ≥ 0。
    前兩條相加：3x + 3y ≤ 12，所以 x + y ≤ 4。這與 x + y ≥ 8 矛盾 → infeasible。

  【常見錯誤】
    • 看到可行域無界，就直接說 unbounded。反例 T1 Q12：Min 4x + 3y，可行域無界，但最小值 24 在 (3,4) 達到。
    • 漏掉 redundant 約束的說明。T1 Q13：x ≤ 12 已被 x + y ≤ 10 蘊含。
  【通用規則】先列出所有頂點；狀態一定要配合代數證明（射線或矛盾）。

6. 常見錯誤與答案驗證
  • 可行域無界 ≠ LP unbounded。〔L1 p25；T1 Q6〕
  • 驗證：把最優點代回每條約束；unbounded 要驗證射線上的每一點都可行。

7. 考試速查
  • 一句話：列頂點、算 Z、比大小；遇到特殊狀態，要給射線、矛盾或平行邊作為證據。

TOPIC 3：判斷一點是否為 CPF
==================================================

1. 題型辨識
  • 題目長相："Determine if the given solution(s) are corner-point feasible solutions"。題目會給一個點和一組不等式。
  • 必須確認：題目有沒有寫 x ≥ 0？有寫的話，非負限制也要算在約束裡。
  • 與 TOPIC 5 的差別：TOPIC 3 用原始的不等式；TOPIC 5 用加了 slack 的等式系統與 basis。

2. 解題邏輯
  • n 維空間中的角落，是 n 片「獨立」的邊界牆交會的點。〔L2 p16–25〕
  • 判斷 CPF 需要同時滿足兩個條件：
      ① 這個點可行。
      ② 所有 active 約束組成的方程組有唯一解。
  • 三種失敗方式
      不可行（T2 Q7(b)）
      active 約束太少（L2 p28）
      active 約束夠多但線性相依（T2 Q1(b)）
  • active 約束多於 n 條，但仍有唯一解 → degenerate CPF。

3. 解題 SOP
  Step 1　把所有約束寫成 ≤ 形式並編號，非負限制也算。
  Step 2　把點代入每條約束，標記：
          active（等號成立）／inactive（嚴格不等）／violated（不成立）
  Step 3　有任何 violated → 不可行 → 不是 CPF，停止。
  Step 4　數 active 的條數 p：
          p < n → 不是 CPF。
          p ≥ n → 進入 Step 5。
  Step 5　解 active 約束組成的方程組（或求係數矩陣的秩）：
          有唯一解（rank = n）→ 是 CPF；若 p > n，則為 degenerate。
          沒有唯一解（rank < n）→ 不是 CPF。

4. 重要公式
  • active 的定義：aᵢᵀx̄ = bᵢ。
  • CPF 判準：x̄ 可行，且由 active 約束組成的係數矩陣 M（每列為一個 aᵢᵀ）滿足 rank(M) = n。

5. 完整實戰案例
  【題目 A，T2 Q7】
    約束：x₁ ≤ 3，x₂ ≤ 3，x₃ ≤ 3，x₁ + x₂ + x₃ ≤ 5（沒有 x ≥ 0）。
    判斷 (3,3,−1) 與 (3,3,3)。
  【題目辨識】給一個點，問是否為 CPF → TOPIC 3。
  【逐步計算】
    (3,3,−1)：
      x₁ = 3 → active
      x₂ = 3 → active
      x₃ = −1 < 3 → inactive
      x₁ + x₂ + x₃ = 5 → active
      → 3 條 active。聯立 x₁ = 3、x₂ = 3、x₁ + x₂ + x₃ = 5，得唯一解 (3,3,−1)；全部約束都成立。
      → 是 CPF。
    (3,3,3)：
      x₁ = x₂ = x₃ = 3 → 3 條 active，有唯一解。
      但 x₁ + x₂ + x₃ = 9 > 5 → violated → 不可行。
      → 不是 CPF。
  【中文解釋】「有唯一交點」只代表它是邊界的交點；交點落在可行域外面，就只是 corner-point infeasible，不是 CPF。

  【題目 B，T2 Q1(b)】
    點 (6½, −5½, −8) 有 4 條 active 約束：
      −2x₁ − 4x₂ + x₃ ≤ 1
      −x₁ − 3x₂ + x₃ ≤ 2
      x₁ + x₂ ≤ 1
      −2x₂ + x₃ ≤ 3
    係數列：(−2,−4,1)、(−1,−3,1)、(1,1,0)、(0,−2,1)
      第 1 列 − 第 2 列 = (−1,−1,0) = −(第 3 列)
      第 4 列 = 第 2 列 + 第 3 列
      → rank = 2 < 3，交集是一條線，不是一個點。
    → 不是 CPF。
  【驗證】把 (3,3,−1) 代回全部約束，全部成立。
  【常見錯誤】
    • 只檢查「唯一解」，忘了檢查可行性。
    • 以為 4 條 active 就一定是 CPF。
  【通用規則】判斷 CPF 一定要兩個條件都檢查：可行性與唯一性（rank = n）。

6. 常見錯誤與答案驗證
  • 題目沒有寫 x ≥ 0 時，不可以自己加上。
  • 驗證：算 active 約束係數矩陣的行列式（剛好 n 條時），或直接把方程組解出來。

7. 考試速查
  • 一句話：先檢查可行，再數 active，最後看 active 方程組的解是否唯一。

TOPIC 4：找 improving edges 與相鄰 CPF（幾何 edge 法）★ FE Q2
==================================================

1. 題型辨識
  • 題目長相：
      "Determine all improving edges emanating from the corner point feasible solution x̄"
      "Determine the CPF at the end of every edge"
      "decide whether x̄ is optimal"
  • 結構：給一組不等式約束（可能沒有 x ≥ 0），加上一個已知的 CPF。
  • 必須確認：
      ① 是 max 還是 min？
      ② 有沒有 x ≥ 0？（FE Q2 有；T2 Q2、Q6、Q8 沒有）
      ③ active 約束有幾條？等於 n 還是多於 n？
  • 與 TOPIC 6 的差別：TOPIC 6 用加了 slack 的等式與 basis（代數法），這裡直接用原始不等式（幾何法）。題目給的是不等式加一個 CPF 時，用這裡的方法。

2. 解題邏輯
  • 站在角落 x̄ 上，只要看從它出發的每一條稜線（edge）：
      有往上坡的 → 那就是 improving edge。
      全部都是下坡 → x̄ 就是最優解。〔L2 p6–9〕
  • 一條 edge = 保留 n−1 條 active 約束為等號，剩下一個自由度 t。
  • 方向：被放鬆的那條 active 約束必須仍然成立，這決定了 t 只能往一邊走。
  • 沿 edge 的目標值 Z(t) 是 t 的一次函數，看斜率正負就知道是不是 improving。
  • 走多遠：往前走時，第一條撞到的 inactive 約束，就是 edge 的另一端。如果沒有任何約束擋住，這條 edge 是一條射線；射線又是 improving 的話，LP 就是 unbounded。
  • 退化：active 多於 n 條時，有些組合會被夾成一個點（不是 edge），有些組合會得到同一條線（只算一次）。

3. 解題 SOP
  Step 1　列出所有約束，編號 (1)(2)…；非負限制標為 (N1)(N2)…；全部寫成 ≤ 形式。
  Step 2　把 x̄ 代入每條約束，列表標出 active／inactive，順便確認可行。
  Step 3　數 active 的條數 p：
          p = n → 共 n 組（每次去掉 1 條）。
          p > n → 共 C(p, n−1) 組；要準備處理「退化 edge」與「重複的線」。
  Step 4　對每一組（保留 n−1 條為等號）：
    4a　解出直線：選一個變數當參數 t，其他變數用 t 表示。
        做法：聯立這 n−1 條等式；常常可以先消去某個變數。
    4b　方向：把直線代入「每一條」剩下的 active 約束，化簡成 t ≥ t₀ 或 t ≤ t₀。
        若同時得到 t ≥ t₀ 和 t ≤ t₀ → 被夾成一點 → 退化，不是 edge，捨棄。
    4c　目標：把直線代入 Z，化成 Z(t) = α + βt。
        沿著允許的方向，Z 嚴格變好（max 遞增、min 遞減）→ improving。
        β = 0 → 不算 improving。
    4d　端點（題目有問時）：把直線代入每一條 inactive 約束（含 x ≥ 0）。
        只保留「沿前進方向會被擋住」的約束，取距離最近的那一條，得到端點。
        沒有任何約束擋住 → ray。
  Step 5　去重：不同組合得到同一條線時，只算一條。
  Step 6　結論：列出所有 improving edges（寫出參數式與範圍）；若沒有，寫「x̄ is optimal」。

4. 重要公式（向量版本，〔補充〕；考卷上照 Step 4 的參數寫法即可）
  • 方向向量 d 滿足：
      aᵢᵀd = 0（i 是保留為等號的 n−1 條）
      aₖᵀd < 0（k 是被放鬆的那條，往可行側走）
  • 最遠步長：
      t_max = min{ (bᵢ − aᵢᵀx̄) / (aᵢᵀd) : i 為 inactive，且 aᵢᵀd > 0 }
      沒有任何 aᵢᵀd > 0 → ray。
  • 沿 edge 的目標值：Z(t) = cᵀx̄ + t·(cᵀd)
      max 問題：cᵀd > 0 → improving
      min 問題：cᵀd < 0 → improving
  • 非退化時：沒有 improving edge ⇒ x̄ 是最優解。〔L2 p7、p69〕

5. 完整實戰案例（FE Q2，依原卷；原卷有 x ≥ 0）
  【題目】
    Maximize Z = 2x₁ + 4x₂ − x₃
    Subject to:
      (1) −x₁ + 2x₂ + x₃ ≤ 3
      (2) 2x₁ + x₂ − 2x₃ ≤ 4
      (3) −3x₁ − x₂ ≤ −5
      (4) x₁ + 3x₂ + 2x₃ ≤ 9
      (5) −x₁ + x₂ − x₃ ≤ 2
      x₁, x₂, x₃ ≥ 0　（記為 N1, N2, N3）
    求從 CPF x̄ = (1,2,0) 出發的所有 improving edges。
  【題目辨識】給不等式加一個 CPF，問 improving edges → TOPIC 4（幾何 edge 法）。
  【解法選擇】題目沒有要求用 simplex；而且在退化 CPF 上，tableau 一次只會顯示一個 basis，看不到所有 edges。所以用幾何法逐組檢查。
  【Step 2：代入 x̄】
    (1) −1 + 4 + 0 = 3 → active
    (2) 2 + 2 − 0 = 4 → active
    (3) −3 − 2 = −5 → active
    (4) 1 + 6 + 0 = 7 < 9 → inactive
    (5) −1 + 2 − 0 = 1 < 2 → inactive
    N1：x₁ = 1 > 0 → inactive；N2：x₂ = 2 > 0 → inactive；N3：x₃ = 0 → active
    → 共 4 條 active，n = 3 → degenerate CPF，要檢查 C(4,2) = 6 組。
    （x̄ 可以由 (1)(2)(3) 三條唯一決定，所以確實是 CPF。）
  【Step 4：六組逐一檢查】
    組 (1)(2)：
      聯立兩式，消去 x₁ 得 5x₂ = 10，所以 x₂ = 2；代回得 x₁ = 1 + x₃。
      令 t = x₃ → x(t) = (1+t, 2, t)
      方向：代入 (3)：−3(1+t) − 2 ≤ −5 → t ≥ 0
            代入 N3：t ≥ 0
            → t 從 0 往上走
      Z(t) = 2(1+t) + 8 − t = 10 + t → 遞增 → improving ✓
      端點：(4)：1 + t + 6 + 2t = 7 + 3t ≤ 9 → t ≤ 2/3（擋住）
            (5)：1 − 2t ≤ 2 → t ≥ −1/2，往上走不會擋住
            → 端點 t = 2/3：(5/3, 2, 2/3)，Z = 32/3
    組 (1)(3)：
      由 (3)：x₂ = 5 − 3x₁；代入 (1)：x₃ = −7 + 7x₁。
      令 t = x₁ → x(t) = (t, 5−3t, −7+7t)
      方向：(2)：19 − 15t ≤ 4 → t ≥ 1；N3：−7 + 7t ≥ 0 → t ≥ 1 → t 往上走
      Z = 2t + 20 − 12t + 7 − 7t = 27 − 17t → 遞減 → 不是 improving
      端點：(4)：1 + 6t ≤ 9 → t ≤ 4/3（最近）；N2：t ≤ 5/3
            → (4/3, 1, 7/3)
    組 (2)(3)：
      x(t) = (t, 5−3t, (1−t)/2)
      方向：(1)：−7.5t + 10.5 ≤ 3 → t ≥ 1
            N3：(1−t)/2 ≥ 0 → t ≤ 1
            → 只剩 t = 1 一個點 → 退化，不是 edge
    組 (1)(N3)：
      x₃ = 0，x₁ = 2x₂ − 3；令 s = x₂ → x(s) = (2s−3, s, 0)
      方向：(2)：5s − 6 ≤ 4 → s ≤ 2
            (3)：−7s + 9 ≤ −5 → s ≥ 2
            → 只剩 s = 2 → 退化，不是 edge
    組 (2)(N3)：
      x(s) = (s, 4−2s, 0)
      方向：(1)：8 − 5s ≤ 3 → s ≥ 1；(3)：−s − 4 ≤ −5 → s ≥ 1 → s 往上走
      Z = 2s + 16 − 8s = 16 − 6s → 遞減 → 不是 improving
      端點：N2：s ≤ 2 → (2, 0, 0)
    組 (3)(N3)：
      x(s) = (s, 5−3s, 0)
      方向：(1)：10 − 7s ≤ 3 → s ≥ 1；(2)：5 − s ≤ 4 → s ≥ 1 → s 往上走
      Z = 2s + 20 − 12s = 20 − 10s → 遞減 → 不是 improving
      端點：N2：s ≤ 5/3 → (5/3, 0, 0)
  【最終答案】
    唯一的 improving edge：{ (1+t, 2, t) : 0 ≤ t ≤ 2/3 }
    沿此 edge，Z 從 10 增加到 32/3。
  【答案驗證】
    • Python 列舉結果相同：共 4 條真正的 edge，其中只有 1 條是 improving。
    • 端點 (5/3, 2, 2/3) 代回：(1) 3 ✓、(2) 4 ✓、(3) −7 ≤ −5 ✓、(4) 9 ✓、(5) −1/3 ≤ 2 ✓、x ≥ 0 ✓。
    • 這個端點正好是整個 LP 的最優解，Z* = 32/3（LP solver 確認）。
  【常見錯誤】
    • 老師詳解檔漏看了 x ≥ 0：只檢查 3 組，把 (2)(3) 當成射線（但那條射線在 t > 1 時 x₃ < 0，不可行），又漏掉 (2)(N3)、(3)(N3)。結論碰巧相同，但 edge 清單是錯的。
    • 只用 (1)(2)(3) 三條約束，沒發現 x₃ = 0 也是 active。
  【通用規則】先數 active 的條數；多於 n 條時，要檢查 C(p, n−1) 組，並刪掉被夾成一點的組合與重複的線。

  補充案例（非退化、需要求端點）：T2 Q4
    Max 5x₁ + 2x₂ + 4x₃
    s.t. x₁ + 2x₂ + x₃ ≤ 9；2x₁ + x₂ + 3x₃ ≤ 12；−x₁ + x₂ + 2x₃ ≤ 3；x₁ + x₃ ≤ 3；x ≥ 0
    x̄ = (2,3,1)，active 為 (1)(3)(4)。
    組 (1)(4)：直線 (3−x₃, 3, x₃)；(3) 化為 3x₃ ≤ 3 → x₃ 往下走
               Z = 21 − x₃，x₃ 往下時 Z 上升 → improving ✓
               端點：x₃ ≥ 0 擋住 → (3,3,0)；它也是最優解，Z = 21。
    其他兩組不是 improving，端點分別為 (1,4,0) 與 (1,0,2)。

6. 常見錯誤與答案驗證
  • 方向憑直覺判斷 → 必須把直線代入每一條剩下的 active 約束。
  • 斜率為 0 的 edge 當成 improving（T2 Q5 第 4–6 組）。
  • 找端點時漏掉非負限制（T2 Q4 第 3 組是被 x₂ ≥ 0 擋住）。
  • 驗證：
      端點要滿足所有約束。
      端點的 active 約束 = 保留的那 n−1 條 + 擋住的那一條。
      improving 的射線 ⇒ LP unbounded（T2 Q2 第 3 組、T2 Q6）。

7. 考試速查
  • 開頭三問：max 還是 min？有沒有 x ≥ 0？active 幾條？
  • 每組寫四行：直線、方向、Z(t)、端點。
  • 一句話：每次保留 n−1 條 active 約束得到一條線，用剩下的 active 約束決定方向，再看 Z 的斜率是否變好。

==================================================
TOPIC 5：判斷 basis／BFS／adjacent bases
==================================================

1. 題型辨識
  • 題目長相：給一個線性方程組 Ax = b（或一個 SIF 的 augmented form），問：
      "Is {…} a (feasible) basis?"
      "Is (…) a basic (feasible) solution?"
      "Are the BFS … adjacent?"
      "Find all bases determining …"
  • 結構：m 條等式、n 個變數，n > m。
  • 與 TOPIC 3 的差別：這裡是等式系統，看的是「哪些變數 = 0」；TOPIC 3 是不等式，看的是「哪些約束 active」。

2. 解題邏輯
  • basis：選 m 個變數，其餘 n−m 個設為 0；若剩下的方程組有唯一解，這 m 個變數就構成 basis。〔L3 p31–35〕
    唯一解 ⇔ B（這 m 欄組成的矩陣）可逆 ⇔ 這 m 欄線性獨立。
  • feasible basis：解出來的值全部 ≥ 0，對應的解叫 BFS。
  • CPF ⇔ BFS：「約束 active」對應「該變數 = 0」。〔L3 p23–27〕
  • adjacent：兩個 basis 恰好差一個變數。〔L3 p45〕
  • degenerate：解中 0 的個數比 n−m 多 → 這個 BFS 由多個 basis 決定。

3. 解題 SOP
  【判斷 basis】
    Step 1　把非基本變數全部設 0。
    Step 2　用 ERO（交換、縮放、加減列）解剩下的 m×m 方程組。
    Step 3　有唯一解 → 是 basis；出現 0 = 非零（無解）或 0 = 0（無限多解）→ 不是 basis。
            也可以直接看各欄是否線性相依（例如某一欄 = 另外兩欄相加）。
    Step 4　值全部 ≥ 0 → feasible basis。
  【判斷一個解是否 basic】
    Step 1　所有非零的變數一定在 basis 裡。
    Step 2　從為 0 的變數中挑出補足 m 個的組合，一一用上面的方法檢查；只要有一個組合是 basis，這個解就是 basic solution。
  【判斷 adjacent】
    兩個 basis 的變數集合恰好差一個 → adjacent（這個關係沒有遞移性）。
  【augmented solution】
    sᵢ = bᵢ − aᵢᵀx̄。

4. 重要公式
  • B = [a_B₁ | … | a_Bm]
  • 是 basis ⇔ det(B) ≠ 0
  • 基本解：x_B = B⁻¹b，x_N = 0
  • BFS ⇔ B⁻¹b ≥ 0

5. 完整實戰案例
  【題目 A，T3 Q3】
    方程組：
      x₁ + 2x₂ − x₃ + x₄ = 5
      −x₁ + x₂ + 2x₄ − x₅ = 1
      2x₁ − x₂ + x₃ − x₅ = 4
    考慮三組變數：{x₁,x₂,x₃}、{x₁,x₂,x₄}、{x₁,x₄,x₅}。
  【題目辨識】給方程組與變數集合 → TOPIC 5。
  【逐步計算】
    {x₁,x₂,x₃}：令 x₄ = x₅ = 0
      方程組：x₁ + 2x₂ − x₃ = 5；−x₁ + x₂ = 1；2x₁ − x₂ + x₃ = 4
      第 1 式 + 第 3 式消去 x₃：3x₁ + x₂ = 9
      與 −x₁ + x₂ = 1 相減：4x₁ = 8，所以 x₁ = 2
      x₂ = 1 + x₁ = 3；x₃ = x₁ + 2x₂ − 5 = 3
      → 解為 (2,3,3,0,0)，全部 ≥ 0 → feasible basis
    {x₁,x₂,x₄}：令 x₃ = x₅ = 0
      第 3 式：x₂ = 2x₁ − 4
      代入第 2 式：x₁ + 2x₄ = 5
      代入第 1 式：5x₁ + x₄ = 13
      解得 x₄ = 4/3，x₁ = 7/3，x₂ = 2/3
      → 解為 (7/3, 2/3, 0, 4/3, 0)，feasible basis
    {x₁,x₄,x₅}：令 x₂ = x₃ = 0
      → 解為 (13/5, 0, 0, 12/5, 6/5)，feasible basis
    adjacency：
      {x₁,x₂,x₃} 與 {x₁,x₂,x₄}：只差 x₃ ↔ x₄ → adjacent
      {x₁,x₂,x₄} 與 {x₁,x₄,x₅}：只差 x₂ ↔ x₅ → adjacent
      {x₁,x₂,x₃} 與 {x₁,x₄,x₅}：差兩個 → 不是 adjacent
  【驗證】把三組解代回原方程組，全部成立（已用 sympy 驗算）。
  【通用規則】adjacent 沒有遞移性：A~B、B~C，推不出 A~C。

  【題目 B，T3 Q5（退化）】
    LP：x₁ + x₂ + x₃ ≤ 6；x₁ − x₂ ≤ 2；x₂ + 2x₃ ≤ 8；x ≥ 0
    點 (2,0,4) 的 augmented solution：s = (0,0,0) → 完整解 (2,0,4,0,0,0)，共 4 個 0。
    m = 3，所以非退化時應該只有 3 個 0；多了一個 → degenerate。
    basis 必須包含非零的 x₁、x₃，再從 {x₂, s₁, s₂, s₃} 選一個：
      {x₁,x₂,x₃}、{x₁,x₃,s₁}、{x₁,x₃,s₂}、{x₁,x₃,s₃}
    四組都是 basis，而且決定同一個 BFS（已用 sympy 枚舉確認）。

  【常見錯誤】
    T3 Q7(a)：{x₁,x₃,x₅} 中，x₅ 的欄 = x₁ 的欄 + x₃ 的欄，三欄線性相依 → 不是 basis。
    用消去法會得到 0 = 6，出現矛盾。

6. 常見錯誤與答案驗證
  • 沒有用「唯一解」判斷，只看是否解得出一組數字。
  • 退化的 BFS 只找到一個 basis。
  • 驗證：把解代回 Ax = b；檢查 det(B) ≠ 0。

7. 考試速查
  • 一句話：非基本變數設 0，解出唯一解就是 basis；值全部非負就是 BFS；兩個 basis 只差一個變數就是 adjacent。

==================================================
TOPIC 6：由 BFS 寫出 edges（代數 edge 法）
==================================================

1. 題型辨識
  • 題目長相：給一個等式系統和一組基本變數，問 "write the edges emanating from the BFS" 或 "does the edge terminate"。
  • 與 TOPIC 4 的差別：TOPIC 4 是不等式加上一個點（幾何法）；這裡是等式加上一個 basis（代數法）。

2. 解題邏輯
  • 每條 edge 對應「讓一個非基本變數從 0 開始增加，其他非基本變數維持 0」。〔L3 p55–58〕
  • 基本變數會隨之變化；一旦某個基本變數降到 0，這條 edge 就到了盡頭（這就是 minimum ratio 的概念）。
  • 若沒有任何基本變數會減少，這條 edge 是一條射線。

3. 解題 SOP
  Step 1　把非基本變數移到等號右邊。
  Step 2　用 ERO 把每個基本變數寫成非基本變數的函數：
          x_Bᵢ = b̄ᵢ − Σⱼ āᵢⱼ x_Nⱼ
  Step 3　BFS：令所有 x_N = 0，得到 x_B = b̄。
  Step 4　對每一個非基本變數 x_Nₖ，寫出 edge：
          x_Nₖ = t，其他 x_N = 0，x_Bᵢ = b̄ᵢ − āᵢₖ t
  Step 5　找盡頭：
          只看 āᵢₖ > 0（也就是 t 增加時會減少）的基本變數。
          t_max = min( b̄ᵢ / āᵢₖ )
          沒有任何一個會減少 → 射線。

4. 重要公式
  • edge：x(t) = BFS + t·（方向），方向中 x_Nₖ 的分量為 1，x_Bᵢ 的分量為 −āᵢₖ。
  • 盡頭：t_max = min{ b̄ᵢ/āᵢₖ : āᵢₖ > 0 }。

5. 完整實戰案例（T3 Q6）
  【題目】
    −x₁ − x₂ + x₃ = 4
    −2x₁ + x₂ + x₄ = 6
    基本變數為 x₃、x₄。寫出所有 edges，並判斷每條 edge 是否有盡頭。
  【題目辨識】等式系統加上 basis {x₃, x₄} → TOPIC 6。
  【逐步計算】
    x₃ = 4 + x₁ + x₂
    x₄ = 6 + 2x₁ − x₂
    BFS = (0, 0, 4, 6)
    Edge 1（x₁ = t，x₂ = 0）：(t, 0, 4+t, 6+2t)
      x₃、x₄ 都隨 t 增加，不會降到 0 → 射線
    Edge 2（x₂ = t，x₁ = 0）：(0, t, 4+t, 6−t)
      x₄ = 6 − t ≥ 0 → t ≤ 6
      → 在 t = 6 到達相鄰的 BFS (0, 6, 10, 0)
  【中文解釋】看 t 在基本變數式中的係數正負：只有會讓某個基本變數減少的那一項，才擋得住 edge。
  【驗證】把 (0,6,10,0) 代回：−6 + 10 = 4 ✓；6 + 0 = 6 ✓。
  【常見錯誤】把 x₃ = 4 + t 也算進 ratio，但它是遞增的，不會擋住。
  【通用規則】一個非基本變數 = 一條 edge；會減少的基本變數，決定這條 edge 在哪裡停下。

  補充案例（L3 p56–59，Wyndor 3D，BFS = (4,3,0,0,6,0)，basis = {x_D, x_W, s₂}）
    基本變數式：
      x_D = 4 − 2x_L − s₁
      x_W = 3 − 1.5x_L + 1.5s₁ − 0.5s₃
      s₂ = 6 − 3x_L − 3s₁ + s₃
    s₁ 這條 edge：x_D = 4 − s₁ → s₁ ≤ 4；s₂ = 6 − 3s₁ → s₁ ≤ 2；x_W 遞增，不擋。
    取較小的 2 → 停在 (2, 6, 0)。

6. 常見錯誤與答案驗證
  • ERO 算錯 → 每一步都把結果代回原方程組驗算（T3 Q1 解出 x₄ 與 x₅ 是同一個式子，這是巧合，不是算錯）。

7. 考試速查
  • 一句話：把基本變數寫成非基本變數的函數，一次只讓一個非基本變數增加，最先降到 0 的基本變數決定 edge 的盡頭。

TOPIC 7：代數 simplex — reduced cost、entering、leaving、pivot
==================================================

1. 題型辨識
  • 題目長相：給 SEF（全部為等式且 x ≥ 0）和一個 feasible basis，問：
      "find the reduced costs"
      "determine the improving edge / entering variable"
      "minimum ratio test / leaving variable"
      "adjacent BFS"
    或要求用代數法做 simplex。
  • 與 TOPIC 9（tableau）的差別：兩者做的是同一件事，只是這裡用方程式寫，TOPIC 9 用表格寫。題目寫 "algebraic" 或沒有指定時，兩種都可以。

2. 解題邏輯
  • 把目標 z 也寫成非基本變數的函數：z = v̄ + Σ c̄ⱼ x_Nⱼ。
    c̄ⱼ（reduced cost）就是沿著 x_Nⱼ 那條 edge 走時，目標的變化率。〔L4 p13–14〕
  • 判斷（max 問題）
      c̄ⱼ > 0 → 這條 edge 是 improving，x_Nⱼ 可以進入（entering）。
      全部 c̄ ≤ 0 → 目前的解是最優解（optimality test）。〔L4 p19〕
  • 進入變數增加時，最先降到 0 的基本變數離開（leaving，由 minimum ratio test 決定）。〔L4 p32〕
  • 若進入變數那一欄沒有任何會減少的基本變數 → unbounded。〔L4 p42〕
  • min 問題：條件全部反過來（c̄ < 0 才進入；全部 c̄ ≥ 0 才最優）。〔L4 p14、p22 手寫〕

3. 解題 SOP
  Step 1（初始）
    用 ERO 把每個基本變數寫成 x_Bᵢ = b̄ᵢ − Σⱼ āᵢⱼ x_Nⱼ。
    代入 z，得到 z = v̄ + Σ c̄ⱼ x_Nⱼ。
  Step 2（entering）
    若沒有 c̄ⱼ > 0 → 最優，停止。
    否則選一個 c̄ⱼ > 0 的變數（依題目規定的 tie-breaking 規則）。
  Step 3（leaving）
    只看 āᵢₖ > 0 的列（在基本變數式中，xₖ 前面是負號的那幾列）。
    t = min( b̄ᵢ / āᵢₖ )，取到最小值的那個基本變數離開。
    沒有任何 āᵢₖ > 0 → unbounded，停止（並依 TOPIC 8 寫出證明）。
  Step 4（pivot）
    用離開變數那一列解出進入變數；代入其他所有列以及 z。
  Step 5　回到 Step 2。

4. 重要公式
  • z = v̄ + Σ c̄ⱼ x_Nⱼ（v̄ = 目前 BFS 的目標值）
  • MRT：t = min{ b̄ᵢ / āᵢₖ : āᵢₖ > 0 }
  • 目標值增加量：Δz = c̄ₖ · t（t = 0 時為退化 pivot，z 不變）

5. 完整實戰案例（T4 Q1；與 L4 p72–77 相同題）
  【題目】
    Max z = x₁ − 3x₃ − 5x₄ − 3x₅ + 3x₆
    s.t.
      (R1) −3x₁ + x₃ + 2x₄ − 2x₅ + x₆ = 0
      (R2) x₁ + 3x₂ − x₄ − 4x₅ − 3x₆ = −10
      (R3) −x₁ − 4x₂ + x₄ + 6x₅ + 4x₆ = 14
      x ≥ 0
    basis = {x₁, x₃, x₆}
  【題目辨識】SEF 加上 basis，要求 reduced cost 與 improving edge → TOPIC 7。
  【初始設定】非基本變數為 x₂、x₄、x₅，先移到等號右邊：
    (R1) −3x₁ + x₃ + x₆ = −2x₄ + 2x₅
    (R2) x₁ − 3x₆ = −10 − 3x₂ + x₄ + 4x₅
    (R3) −x₁ + 4x₆ = 14 + 4x₂ − x₄ − 6x₅
  【逐步計算】
    R1 ← R1 + 3·R2：x₃ − 8x₆ = −30 − 9x₂ + x₄ + 14x₅
    R3 ← R3 + R2：x₆ = 4 + x₂ − 2x₅
      （解釋：R2 已經單獨含 x₁，所以用它來消去其他列中的 x₁。）
    回代：
      x₃ = −30 − 9x₂ + x₄ + 14x₅ + 8(4 + x₂ − 2x₅) = 2 − x₂ + x₄ − 2x₅
      x₁ = −10 − 3x₂ + x₄ + 4x₅ + 3x₆ = 2 + x₄ − 2x₅
    代入 z：
      z = (2 + x₄ − 2x₅) − 3(2 − x₂ + x₄ − 2x₅) − 5x₄ − 3x₅ + 3(4 + x₂ − 2x₅)
        = 8 + 6x₂ − 7x₄ − 5x₅
    reduced cost：c̄₂ = 6，c̄₄ = −7，c̄₅ = −5 → 只有 x₂ 為正 → x₂ 進入
    improving edge：{ (2, x₂, 2−x₂, 0, 0, 4+x₂) }
    MRT：
      x₁ = 2，不含 x₂ → 不擋
      x₃ = 2 − x₂ → x₂ ≤ 2
      x₆ = 4 + x₂，遞增 → 不擋
      → t = 2，x₃ 離開
    相鄰的 BFS：(2, 2, 0, 0, 0, 6)，basis 變成 {x₁, x₂, x₆}
  【最終答案】c̄ = (6, −7, −5)；x₂ 進入、x₃ 離開；新 BFS 為 (2,2,0,0,0,6)。
  【答案驗證】
    把新 BFS 代回：R1：−6 + 0 + 6 = 0 ✓；R2：2 + 6 − 18 = −10 ✓；R3：−2 − 8 + 24 = 14 ✓
    z = 2 + 18 = 20 = 8 + 6·2 ✓（Δz = c̄·t）
    LP solver 也確認 20 就是最優值。
  【常見錯誤】
    • 消去時把非基本變數留在等號左邊，導致符號錯。
    • 在 MRT 裡把遞增的 x₆ 也算進去。
  【通用規則】先把基本變數全部用非基本變數表示，再代入 z；z 中各非基本變數的係數就是 reduced cost。

  補充案例（T4 Q2，退化 pivot）
    basis {x₁, x₅, x₆}，z = −1 + 7x₂ − 9x₃ − 8x₄
    x₂ 進入；ratio：x₁ 列 2/4，x₆ 列 0/1 → t = 0，x₆ 離開
    pivot 後 z = −1 − 7x₆ − 9x₃ − x₄，全部 ≤ 0 → 最優，z* = −1
    這次 BFS 沒有改變，但 basis 換了；換成新 basis 後，reduced cost 才顯示出它已經是最優。

6. 常見錯誤與答案驗證
  • 代數式寫成 x_B = b̄ − ā x_N 的形式時，MRT 只看 ā > 0 的列。注意講義 L4 p39 說的「需要 NEGATIVE coefficient」，是指 x_B 式中 x_N 前面的整體係數（即 −ā）為負。
  • 驗證：新 BFS 要滿足原本的所有方程式；Δz = c̄·t。

7. 考試速查
  • 停止條件：沒有任何 c̄ > 0（最優）；或進入那一欄沒有 ā > 0（unbounded）。
  • 一句話：把 z 寫成非基本變數的函數，係數為正的變數進入，最先降到 0 的基本變數離開。

TOPIC 8：證明最優／證明 unbounded（構造證明）
==================================================

1. 題型辨識
  • 題目長相："prove that the BFS is optimal"、"give an algebraic proof"、"prove the LP is unbounded"、"give a sequence of feasible solutions to demonstrate unboundedness"。
  • 前提：已經用代數法或 tableau 求出 z = v̄ + Σ c̄ⱼ x_Nⱼ。

2. 解題邏輯
  • 證明最優：z = v̄ + Σ c̄ⱼ x_Nⱼ 這個式子對每一個滿足等式的點都成立。若所有 c̄ⱼ ≤ 0，又因為可行點的 x_N ≥ 0，所以每個可行點的 z ≤ v̄。〔L4 p20–21〕
  • 證明 unbounded：存在 c̄ₖ > 0 的變數 xₖ，而且它那一欄所有 āᵢₖ ≤ 0。令 xₖ = l，基本變數照式子算，其他非基本變數為 0。則對所有 l ≥ 0 都可行，而 z(l) → ∞。〔L4 p43〕

3. 解題 SOP
  【證明最優】
    Step 1　寫出 z = v̄ + Σ c̄ⱼ x_Nⱼ，並指出所有 c̄ⱼ ≤ 0。
    Step 2　「For any feasible x̄：z̄ = v̄ + Σ c̄ⱼ x̄_Nⱼ ≤ v̄，since c̄ⱼ ≤ 0 and x̄_Nⱼ ≥ 0.」
    Step 3　結論：BFS 的值就是 v̄，所以它是最優解。
  【證明 unbounded】
    Step 1　指出 xₖ 的 c̄ₖ > 0，而且每個基本變數都隨 xₖ 增加或不變。
    Step 2　定義 x̄(l)：xₖ = l、其他非基本變數 = 0、基本變數依式子代入。
    Step 3　逐一驗證每個分量 ≥ 0（對所有 l ≥ 0），並且等式成立。
    Step 4　寫出 z(l) = v̄ + c̄ₖ·l → ∞（當 l → ∞）。

4. 重要公式
  • z̄ = v̄ + Σ c̄ⱼ x̄_Nⱼ ≤ v̄
  • x̄(l) = 基本解 + l·（edge 方向），z(l) = v̄ + c̄ₖ l

5. 完整實戰案例
  【題目 A，T4 Q3】
    Max x₁ + x₂，s.t. x₁ + 2x₃ + x₄ = 6，x₂ − x₃ + 3x₄ = 4，x ≥ 0；basis {x₁, x₂}
  【計算】
    x₁ = 6 − 2x₃ − x₄
    x₂ = 4 + x₃ − 3x₄
    z = 10 − x₃ − 4x₄ → c̄₃ = −1，c̄₄ = −4，都 ≤ 0
  【證明】
    任取可行解 x̄：z̄ = 10 − x̄₃ − 4x̄₄ ≤ 10（因為 x̄₃, x̄₄ ≥ 0）。
    而 BFS (6,4,0,0) 的 z = 10，所以它是最優解，z* = 10。

  【題目 B，T4 Q4】
    Max x₁ + x₂，s.t. x₁ − x₃ + x₄ = 5，x₂ − 2x₃ + 3x₄ = 2，x ≥ 0；basis {x₁, x₂}
  【計算】
    x₁ = 5 + x₃ − x₄
    x₂ = 2 + 2x₃ − 3x₄
    z = 7 + 3x₃ − 4x₄ → x₃ 進入
    但 x₁、x₂ 都隨 x₃ 增加 → 沒有離開變數
  【證明】
    令 x̄(l) = (5+l, 2+2l, l, 0)，l = 0, 1, 2, …
    等式：(5+l) − l + 0 = 5 ✓；(2+2l) − 2l + 0 = 2 ✓
    非負：每個分量都 ≥ 0 ✓
    z(l) = 7 + 3l → ∞
    → LP unbounded。
  【常見錯誤】只說「沒有離開變數，所以 unbounded」，沒有寫出序列並驗證可行性。
  【通用規則】最優性證明靠「c̄ ≤ 0 且 x ≥ 0」；unbounded 證明靠「寫出一條可行射線，目標趨向無限大」。

6. 常見錯誤與答案驗證
  • 最優性證明要強調：這個 z 的式子對「所有可行解」成立，不只是對 BFS。
  • unbounded 序列要同時驗證兩件事：等式成立、非負成立。

7. 考試速查
  • 一句話：最優性看 c̄ ≤ 0 加上 x ≥ 0；unbounded 就寫出 x̄(l) 並證明 z → ∞。

TOPIC 9：Tableau simplex（含退化 pivot）
==================================================

1. 題型辨識
  • 題目長相："apply the simplex method in tabular form"、"starting from the basis …"。
  • 結構：SEF，並給定（或可以直接看出）一個 feasible basis，例如全部是 slack。
  • 與 TOPIC 11 的差別：沒有現成的 feasible basis 時（約束有 ≥、=，或 RHS 為負），要改用 two-phase。
  • 與 TOPIC 12 的差別：題目寫 revised 時，要改用 B⁻¹ 的做法。

2. 解題邏輯
  • tableau 的每一列是一條方程式。z-row 是 z − Σ c̄ⱼxⱼ = v̄，所以 z-row 裡存的是 −c̄。〔L5 p6–9〕
  • max 問題：z-row 全部 ≥ 0 → 最優；有負數 → 那一欄可以進入。
  • min 問題：z-row 全部 ≤ 0 → 最優；有正數 → 那一欄可以進入。〔L5 p9；L6 p20〕
  • pivot = Gauss–Jordan 消去：把進入欄變成單位向量。〔L5 p19〕
  • 退化：RHS 為 0 的列參與 ratio 時，t = 0，z 不變，但 basis 改變。

3. 解題 SOP
  Step 0（初始）
    確認每個基本變數的欄是單位向量，且 z-row 中基本變數的位置是 0。
    若不是，先用列運算把它們消掉（例如 T5 Q1：把第 2 列換成第 2 列 − 第 3 列）。
  Step 1（entering）
    max：z-row 為負的欄可以進入；min：z-row 為正的欄可以進入。
    沒有可以進入的欄 → 最優，停止。
  Step 2（MRT）
    對進入欄中「> 0」的列，計算 RHS / 係數，取最小值。
    係數 ≤ 0 的列排除（作答時標「—」）。
    沒有任何 > 0 的列 → unbounded，停止。
  Step 3（pivot）
    pivot 列 ← pivot 列 ÷ pivot 元素
    其他每一列（含 z-row） ← 該列 −（該列在進入欄的係數）× 新 pivot 列
  Step 4　檢查：每個基本變數的欄是單位向量、RHS 全部 ≥ 0。回到 Step 1。
  Step 5　讀答案：基本變數 = RHS；非基本變數 = 0；z* = z-row 的 RHS。

4. 重要公式（L5 p19）
  • pivot 列：row_r ← (1/ā_rk)·row_r
  • z-row：z-row ← z-row + (c̄ₖ/ā_rk)·row_r（即消去 z-row 中進入欄的 −c̄ₖ）
  • 其他列 i ≠ r：row_i ← row_i − (ā_ik/ā_rk)·row_r
  • 以上都使用 pivot 前的原 pivot 列。

5. 完整實戰案例（T5 Q4，包含平手與退化）
  【題目】
    Max 5x₃ + 2x₄
    s.t. x₁ + x₃ − x₄ = 2；x₂ + x₃ + x₄ = 2；x ≥ 0
    起始 basis {x₁, x₂}
  【題目辨識】SEF，basis 現成（x₁、x₂ 各自只出現在一列），要求 tabular → TOPIC 9。
  【初始 tableau】
          x₁   x₂   x₃   x₄  │ RHS
    z  │  0    0   −5   −2  │  0
    x₁ │  1    0    1   −1  │  2
    x₂ │  0    1    1    1  │  2
  【Iteration 1】
    z-row 的負數：x₃ (−5)、x₄ (−2)。依 largest coefficient → x₃ 進入。
    MRT：x₁ 列 2/1 = 2；x₂ 列 2/1 = 2 → 平手。依 smallest subscript，x₁ 離開。
    pivot 元素 = 1（x₁ 列、x₃ 欄）。
    z-row ← z-row + 5·(x₁ 列)；x₂ 列 ← x₂ 列 − 1·(x₁ 列)
          x₁   x₂   x₃   x₄  │ RHS
    z  │  5    0    0   −7  │ 10
    x₃ │  1    0    1   −1  │  2
    x₂ │ −1    1    0    2  │  0
    解釋：x₂ = 0 是基本變數 → 這是退化的 BFS (0,0,2,0)。原因是剛才的平手。
  【Iteration 2】
    x₄ 進入（z-row 唯一的負數 −7）。
    MRT：x₃ 列係數 −1 → 排除；x₂ 列 0/2 = 0 → t = 0，x₂ 離開。這是退化 pivot。
    x₂ 列 ÷ 2 → (−½, ½, 0, 1 │ 0)
    z-row ← z-row + 7·(新 x₂ 列)；x₃ 列 ← x₃ 列 + 1·(新 x₂ 列)
          x₁    x₂   x₃   x₄  │ RHS
    z  │ 3/2   7/2   0    0  │ 10
    x₃ │ 1/2   1/2   1    0  │  2
    x₄ │ −1/2  1/2   0    1  │  0
  【最終答案】z-row 全部 ≥ 0 → 最優。x* = (0, 0, 2, 0)，z* = 10。
  【答案驗證】
    代回：0 + 2 − 0 = 2 ✓；0 + 2 + 0 = 2 ✓；z = 5·2 = 10 ✓
    LP solver 也得到 10。
  【中文解釋】第二次 pivot 時 z 沒有改變，但換了 basis 之後，z-row 才顯示出最優。
  【常見錯誤】
    • MRT 時把 x₃ 列的 −1 也拿來算。
    • 看到 t = 0 就誤以為算錯。
  【通用規則】ratio 出現平手 → 下一步很可能是退化 pivot；繼續照規則做，不需要特別處理。

  補充案例（T5 Q1，unbounded）
    初始時需要先做列運算（第 2 列 − 第 3 列）才能讓 x₂ 單獨在一列。
    初始 z-row：(0, 0, 8, −8, 0, 9 │ −1)
    x₄ 進入、x₂ 離開 → z-row 變成 (0, 8, 0, 0, 0, −7 │ 7)
    x₆ 進入，但它那一欄為 (0, −2, −1)，沒有正數 → unbounded
    證明：x̄(k) = (1, 0, 0, 1+2k, 2+k, k)，z = 7 + 7k → ∞

6. 常見錯誤與答案驗證
  • z-row 的正負號弄反。
  • pivot 時用到已經改過的其他列。
  • 驗證：每個基本變數的欄都是單位向量；把 x* 代回原約束；最後的 z 要等於 cᵀx*。

7. 考試速查
  • 停止條件：max 時 z-row 全部 ≥ 0（min 時全部 ≤ 0）→ 最優；進入欄沒有正數 → unbounded。
  • 一句話：選 z-row 的負數欄進入（max），用 MRT 選離開的列，做 Gauss–Jordan 消去，一直重複到 z-row 沒有負數。

TOPIC 10：Tie-breaking 規則（largest coefficient、largest improvement、Bland）
==================================================

1. 題型辨識
  • 題目長相：給一個 tableau，問在 (a) largest coefficient (b) largest improvement (c) Bland's rule 之下，進入與離開的變數各是哪一個。
  • 題目或過程中出現「平手」、「cycling」、「degenerate」等字眼。

2. 解題邏輯〔L5 p33–48〕
  • Largest coefficient（LC）：選 c̄ 最大者進入。直覺、容易算，但結果會受到單位縮放影響。
  • Smallest subscript：選下標最小的候選者。計算最簡單。
  • Largest improvement（LI）：每個候選者都先做 MRT 得到 t，再選 Δz = c̄·t 最大者。結果不受縮放影響，但計算量大。
  • Bland's rule：進入用最小下標；離開時若平手，也用最小下標 → 保證不會 cycling。
    比的是「變數的下標」，不是在第幾列。
  • 只要不遇到 degenerate basis，simplex 一定在有限步內結束。cycling 必定伴隨退化 pivot（t = 0）。

3. 解題 SOP
  Step 1　列出所有候選進入變數（max：z-row 為負的欄），寫出各自的 c̄ = −（z-row 值）。
  Step 2　對每個候選者做 MRT，寫出 t 以及取到 t 的列（若平手，全部列出）。
  Step 3　計算 Δz = c̄·t。
  Step 4　依題目規則選進入變數。
  Step 5　依規則選離開變數（題目要求 smallest subscript 或 Bland 時，平手就選下標最小的變數）。

4. 重要公式
  • Δz = c̄ₖ · t，t = min{ RHSᵢ / āᵢₖ : āᵢₖ > 0 }

5. 完整實戰案例（T5 Q3）
  【題目】max 問題的 tableau（列依序對應基本變數 x₇、x₁、x₆、x₄）：
          x₁  x₂  x₃  x₄  x₅  x₆  x₇ │ RHS
    z  │  0  −3  −1   0  −7   0   0 │  5
    x₇ │  0   4  −5   0   4   0   1 │ 16
    x₁ │  1  −3   2   0  −5   0   0 │  0
    x₆ │  0  −5   3   0   3   1   0 │ 12
    x₄ │  0   8   8   1   9   0   0 │ 32
  【逐步計算】
    候選進入變數：x₂ (c̄ = 3)、x₃ (c̄ = 1)、x₅ (c̄ = 7)
    x₂：x₇ 列 16/4 = 4、x₄ 列 32/8 = 4（平手）；x₁、x₆ 列為負，排除 → t = 4，Δz = 12
    x₃：x₁ 列 0/2 = 0、x₆ 列 12/3 = 4、x₄ 列 32/8 = 4；x₇ 列為負，排除 → t = 0，Δz = 0（退化）
    x₅：x₇ 列 16/4 = 4、x₆ 列 12/3 = 4、x₄ 列 32/9 = 3⁵⁄₉；x₁ 列為負，排除 → t = 3⁵⁄₉，Δz = 7 × 32/9 = 24⁸⁄₉
  【最終答案】
    (a) LC：x₅ 進入（c̄ = 7 最大）、x₄ 離開
    (b) LI：x₅ 進入（Δz = 24⁸⁄₉ 最大）、x₄ 離開
    (c) Bland：x₂ 進入（下標最小）；x₇ 與 x₄ 平手，x₄ 離開（下標 4 < 7，雖然 x₄ 在第 4 列）
  【驗證】Δz 要用 t 計算，不是用 pivot 元素。
  【常見錯誤】
    • Bland 離開時比的是列的位置。
    • LI 忘了 t 可能是 0（x₃ 這一欄）。
  【通用規則】先把候選者、c̄、t、Δz 列成一張表，再依規則挑選。

  補充（L5 p37–38）：c̄ 為 3、4、1 的三個候選者，t 分別為 1/2、3/8、2，Δz 分別為 1.5、1.5、2。LI 選的是 c̄ 最小的 x₆，可見 LC 與 LI 的結果可以不同。

6. 常見錯誤與答案驗證
  • 只有 Bland 能保證不 cycle；LC 會 cycle（L5 p44–46 的 Beale 例子，z 一直停在 17）。

7. 考試速查
  • 一句話：把候選者的 c̄、t、Δz 列表後依規則挑選；Bland 的進入和離開都比變數下標。

==================================================
TOPIC 11：Two-phase simplex（tabular）★ FE Q3
==================================================

1. 題型辨識
  • 題目長相：
    - "Write down the artificial problem"
    - "use Phase 1 to determine whether the LP is feasible"
    - "continue to Phase 2"
    - "two-phase simplex"
  • 數學結構：約束中有 ≥、=，或 RHS 為負，所以原點不可行，沒有現成的可行基底。
  • 必須先確認：
    ① 每一條約束的型別（≤、≥、=）。
    ② 是否有不受符號限制（free）的變數。
    ③ 每一列 RHS 的正負號。
  • 與 TOPIC 9 的差別：TOPIC 9 從一開始就有可行基底，例如全部是 slack 且 b ≥ 0。

2. 解題邏輯
  • 核心想法：沒有起點，就先造一個起點。
    - 在缺少起點的列加上人工變數 w。
    - 先最小化 Σw（Phase 1）。
    - 若能把所有 w 壓到 0，就得到原問題的可行基底；否則原問題不可行。
  • 定理：原問題可行 ⇔ artificial problem 的最優值為 0。〔L6 p26；T6 Q5〕
  • Phase 1 是 min 問題。在 tableau 中，W 列為正的變數才能進入。
  • Phase 1 結束時：
    - W* > 0 → 原問題 infeasible，停止。
    - W* = 0 → 原問題 feasible，進入 Phase 2。
    - 若仍有 w 在基底中，它的值一定是 0，要先把它換掉。〔L6 p31–39〕
  • Phase 2：換回原本的目標函數，從 Phase 1 得到的可行基底繼續做 simplex。
    結果可能是 optimal 或 unbounded（L6 p47–49 的例子結果是 unbounded）。

3. 解題 SOP
  Step 1　轉成 SEF
          ≤：加 slack（+s）
          ≥：減 surplus（−s）
          free 變數：拆成 x = x⁺ − x⁻
  Step 2　逐列套用三條規則決定是否加 artificial〔L6 p14〕
          規則 1：若某個變數「只出現在這一列」，可以把它當作這一列的 slack。
          規則 2：若它的係數與 RHS 同號，這一列不需要 artificial。
                 （需要時先把整列縮放，讓係數變成 ±1。）
          規則 3：否則加入一個 artificial w，係數取 ±1，與 RHS 同號。
  Step 3　完整寫出 artificial problem：
          min W = Σ w
          s.t. 上面所有等式
               所有變數 ≥ 0
  Step 4　初始 W 列：把所有含 w 的列相加（w 那幾欄填 0），RHS 也相加。
          這一步就是用約束把基本的 w 從 W 中消掉。
  Step 5　Phase 1 迭代（建議使用 Bland）
          進入：W 列為正的欄
          MRT：只看該欄 > 0 的列
          pivot：同 TOPIC 9
          w 離開基底之後，可以刪掉它那一欄。
  Step 6　Phase 1 結束（W 列全部 ≤ 0）
          W* > 0 → 原問題 infeasible，結束。
          W* = 0，但還有 w 在基底中 → 在那一列找任一個係數 ≠ 0 的非基本原變數（正負都可以）做 pivot。
          這是退化 pivot（t = 0），所有變數的值都不變。
  Step 7　Phase 2 初始化
          刪掉所有 w 欄。
          用 Phase 1 最終表把每個基本變數寫成非基本變數的函數。
          代入原目標 Z，得到 Z = 常數 + Σ(係數)·x_N，寫成 z-row。
  Step 8　Phase 2 迭代：依原問題是 max 或 min 的規則做 TOPIC 9，直到 optimal 或 unbounded。
  Step 9　結論
          "W* = 0 ⇒ the LP is feasible."
          寫出 x*、Z*；若是 unbounded，寫出可行射線。

4. 重要公式
  • 定理：原問題可行 ⇔ min Σw = 0。
  • W 列 =（含 w 的各列相加），w 的欄 = 0。
  • 殘留 artificial 的處理（revised 版，L8 p10）：
      ā_rⱼ = (B⁻¹ 的第 r 列)·aⱼ
      找任一個 ≠ 0 的 j 做 pivot。

5. 完整實戰案例（FE Q3）
  【題目】
    Maximize Z = 2x₁ + x₂ + x₃
    Subject to:
      −x₁ + 2x₂ = 1
      x₁ + x₂ + x₃ ≥ 2
      x₁ − x₂ + x₃ = 2
      x₁, x₂, x₃ ≥ 0

  【題目辨識】約束有 = 和 ≥，題目也要求寫出 artificial problem，所以用 two-phase。

  【解法選擇】原點 (0,0,0) 不滿足第 1、3 式，找不到現成的可行基底，必須先做 Phase 1。

  【初始設定】
    第 2 式減去 surplus s₅：x₁ + x₂ + x₃ − s₅ = 2。
    逐列判斷：
      第 1 列：沒有只出現在這一列的變數 → 加 w₄。
      第 2 列：s₅ 只出現在這一列，但係數 −1，與 RHS 2 異號 → 加 w₆。
      第 3 列：沒有只出現在這一列的變數 → 加 w₇。
    Artificial problem：
      min W = w₄ + w₆ + w₇
      s.t.
        −x₁ + 2x₂ + w₄ = 1
        x₁ + x₂ + x₃ − s₅ + w₆ = 2
        x₁ − x₂ + x₃ + w₇ = 2
        x₁, x₂, x₃, s₅, w₄, w₆, w₇ ≥ 0
    初始 W 列：三列相加得 W = 5 − x₁ − 2x₂ − 2x₃ + s₅，也就是 W + x₁ + 2x₂ + 2x₃ − s₅ = 5。

  【Phase 1 初始表】
         x₁   x₂   x₃   w₄   s₅   w₆   w₇ │ RHS
    W  │  1    2    2    0   −1    0    0 │  5
    w₄ │ −1    2    0    1    0    0    0 │  1
    w₆ │  1    1    1    0   −1    1    0 │  2
    w₇ │  1   −1    1    0    0    0    1 │  2

  【Iteration 1】
    W 列為正的欄：x₁、x₂、x₃。依 Bland 取下標最小的 x₁ 進入。
    （解釋：這是 min 問題，W 列為正才代表 W 會下降。）
    MRT：w₄ 列係數 −1，排除；w₆ 列 2/1 = 2；w₇ 列 2/1 = 2。
    平手，依 Bland 由 w₆ 離開。
    列運算：
      R_W ← R_W − R_w₆
      R_w₄ ← R_w₄ + R_w₆
      R_w₇ ← R_w₇ − R_w₆
    （w₆ 已離開基底，刪除它那一欄。）
         x₁   x₂   x₃   w₄   s₅   w₇ │ RHS
    W  │  0    1    1    0    0    0 │  3
    w₄ │  0    3    1    1   −1    0 │  3
    x₁ │  1    1    1    0   −1    0 │  2
    w₇ │  0   −2    0    0    1    1 │  0
    （w₇ = 0 但仍是基本變數，這個 BFS 已經退化。）

  【Iteration 2】
    W 列為正的欄：x₂、x₃。依 Bland 取 x₂ 進入。
    MRT：w₄ 列 3/3 = 1；x₁ 列 2/1 = 2；w₇ 列係數 −2，排除。由 w₄ 離開。
    列運算：
      R_w₄ ← R_w₄ / 3
      再用新的 w₄ 列消去其他各列的 x₂。
    （刪除 w₄ 欄。）
         x₁   x₂    x₃     s₅   w₇ │ RHS
    W  │  0    0   2/3    1/3    0 │  2
    x₂ │  0    1   1/3   −1/3    0 │  1
    x₁ │  1    0   2/3   −2/3    0 │  1
    w₇ │  0    0   2/3    1/3    1 │  2

  【Iteration 3】老師詳解的路徑
    s₅ 進入（W 列為正）。
    只有 w₇ 列在 s₅ 欄的係數為正：t = 2 / (1/3) = 6，由 w₇ 離開。
    列運算：
      R_w₇ ← 3·R_w₇
      再用它消去其他各列的 s₅。
         x₁   x₂   x₃   s₅ │ RHS
    W  │  0    0    0    0 │  0
    x₂ │  0    1    1    0 │  3
    x₁ │  1    0    2    0 │  5
    s₅ │  0    0    2    1 │  6
    W* = 0，所以原問題 feasible；artificial 都已離開基底。

  【另一條合法路徑】
    若在 Iteration 3 嚴格照 Bland，應該由 x₃ 進入（下標 3 < 5）。
    - MRT：3、3/2、3 → 由 x₁ 離開。
    - 下一步由 s₅ 進入、w₇ 離開，Phase 1 結束時基底為 {x₂, x₃, s₅}。
    - Phase 2 起始 z-row 為 (−2, 0, 0, 0 │ 3)：x₁ 進入、x₃ 離開，之後得到與老師路徑相同的最終表。
    題目沒有指定使用哪種規則，所以兩條路徑都正確。

  【Phase 2】
    從 Phase 1 最終表讀出：
      x₂ = 3 − x₃
      x₁ = 5 − 2x₃
      s₅ = 6 − 2x₃
    代入原目標：
      Z = 2(5 − 2x₃) + (3 − x₃) + x₃ = 13 − 4x₃
      → Z + 4x₃ = 13
         x₁   x₂   x₃   s₅ │ RHS
    Z  │  0    0    4    0 │ 13
    x₂ │  0    1    1    0 │  3
    x₁ │  1    0    2    0 │  5
    s₅ │  0    0    2    1 │  6
    這是 max 問題，z-row 全部 ≥ 0，所以已經是最優。

  【最終答案】
    (x₁*, x₂*, x₃*) = (5, 3, 0)，Z* = 13（s₅ = 6）

  【答案驗證】
    代回原約束：
      −5 + 6 = 1 ✓
      5 + 3 + 0 = 8 ≥ 2 ✓
      5 − 3 + 0 = 2 ✓
    目標值：2·5 + 3 = 13 ✓
    LP solver 的結果相同；兩條路徑都已用分數精確計算重做。

  【常見錯誤】
    • 初始 W 列沒有消去基本變數 w。
    • Phase 1 用 max 的進入規則（應該是 W 列為正才進入）。
    • Phase 2 的 z-row 直接寫成 −c，沒有代入基本變數。
    • 把 surplus 寫成 +s。

  【通用規則】先寫出完整的 artificial problem，W 列 = 含 w 的各列相加；Phase 1 結束判斷可行性；Phase 2 要先代換掉基本變數，再開始迭代。

  補充案例 1（T6 Q3：殘留 artificial）
    Phase 1 結束時 W* = 0，但 w₃ 仍在基底中，所在列為 (0, 0, 0, 1 │ 0)。
    x₄ 在這一列的係數 = 1 ≠ 0 → 對 (w₃, x₄) 做 pivot。這是退化 pivot，t = 0。
    得到可行基底 {x₂, x₁, x₄}，BFS = (4, 2, 0, 0)。

  補充案例 2（T6 Q2：infeasible）
    Phase 1 四次迭代後 W 列全部 ≤ 0，但 W* = 2 > 0 → 原問題 infeasible。

  補充案例 3（L6 p43–49：Phase 2 發現 unbounded）
    Phase 2 起始 z-row 為 (−20, 0, 0, −3/2, 0 │ −7)。
    x₁ 進入，但它那一欄全部為負 → unbounded。
    驗證：令 x₁ = t，則 x₂ = 9/5 + t/5、x₃ = 1 + 4t、x₅ = 8/5 + 17t/5，z(t) = 20t − 7 → ∞。

6. 常見錯誤與答案驗證
  • artificial 的係數符號沒有跟 RHS 一致（L6 p17 的 w₁ 係數為 −1）。也可以先把整列乘 −1。
  • 判斷某列能否不加 artificial 時，忘了檢查該變數是否「只出現在這一列」。
  • 驗證：
    - Phase 1 結束時，可行基底的值要 ≥ 0，並且滿足原約束。
    - 最後要求 cᵀx* = z-row 的 RHS。

7. 考試速查
  • 停止條件：
    - Phase 1：W 列全部 ≤ 0。W* > 0 → infeasible；W* = 0 → 進入 Phase 2。
    - Phase 2：依原問題的規則判斷 optimal 或 unbounded。
  • 最容易漏掉的步驟：
    - 寫出完整的 artificial problem。
    - 寫出結論句「W* = 0 ⇒ feasible」。
    - 清除殘留的 artificial。
  • 一句話：先最小化人工變數的總和來找可行起點，W* 是 0 才換回原目標繼續 simplex。

==================================================
TOPIC 12：Revised simplex（含 Bland）★ FE Q4
==================================================

1. 題型辨識
  • 題目長相：
    - "Apply the revised simplex method"
    - "using Bland's rule"
    - 題目直接給 B⁻¹、J_B、x_B*，要求做下一步
  • 結構：通常是 SIF（max，約束為 ≤，b ≥ 0），先加 slack；也可以接在 two-phase 之後（L8 Part 1）。
  • 與 TOPIC 9 的差別：
    - 不畫整張 tableau，只維護 B⁻¹。
    - 題目寫 revised，就一定要用這個方法。

2. 解題邏輯
  • 所有需要的量都能從 B⁻¹ 加上原始資料 A、b、c 算出來。〔L7 p13–45〕
    - x_B = B⁻¹b
    - y = c_Bᵀ B⁻¹（y 就是 simplex multipliers，也是對偶解）
    - c̄ⱼ = cⱼ − y·aⱼ
    - d = B⁻¹aₖ（等於 tableau 中進入變數那一欄）
  • 換基底之後，B⁻¹ 不必重新求逆：對舊的 B⁻¹ 做「把 d 變成 eᵣ」的列運算即可。〔L7 p29–30；T7 Q5〕
  • 判斷：
    - max：所有 c̄ ≤ 0 → 最優
    - min：所有 c̄ ≥ 0 → 最優〔L8 p12〕
    - 沒有任何 dᵢ > 0 → unbounded

3. 解題 SOP
  初始化
    • 加上 slack，寫出 A、b、c，並固定變數的順序。
    • J_B = (s₁, …, s_m)，B = B⁻¹ = I，x_B = b。
  每次迭代
    Step 1　寫出 J_B（有順序）、x_B*，以及順序與 J_B 一致的 c_B。
    Step 2　y = c_Bᵀ B⁻¹（列向量 × 矩陣）。
    Step 3　對每個非基本變數算 c̄ⱼ = cⱼ − y·aⱼ。
            slack 的 c̄ 就是 −yᵢ。
            全部 ≤ 0（max）→ 最優，停止。
    Step 4　選進入變數。
            Bland：在 c̄ > 0 的變數中選下標最小者。
            其他規則照題目指定。
    Step 5　d = B⁻¹aₖ。
    Step 6　Ratio test：只看 dᵢ > 0 的位置，計算 x_Bᵢ / dᵢ，取最小值 t。
            平手時，依 Bland 選下標最小的變數離開。
            沒有任何 dᵢ > 0 → unbounded，停止。
    Step 7　更新 J_B：在離開變數原本的位置 r 放入進入變數。不要調換欄的位置。〔L7 p43〕
    Step 8　更新 x_B：
            x_Bᵢ ← x_Bᵢ − dᵢ·t（i ≠ r）
            第 r 個位置 ← t
    Step 9　更新 B⁻¹：
            R_r ← R_r / d_r
            Rᵢ ← Rᵢ − dᵢ·R_r(新)（i ≠ r）
    Step 10　驗算：新 z = 舊 z + c̄ₖ·t。然後回到 Step 1。
  結束
    • 寫出 x*（含原變數）與 z*。
    • 檢查 bᵀy = z*。

4. 重要公式
  • x_B* = B⁻¹b
  • y = c_Bᵀ B⁻¹
  • c̄ⱼ = cⱼ − y·aⱼ
  • d = B⁻¹aₖ
  • t = min{ x_Bᵢ / dᵢ : dᵢ > 0 }
  • B⁻¹ 更新：E·B⁻¹ = B_new⁻¹，E 就是把 d 變成 eᵣ 的那組列運算
  • 直接求逆：對 [B | I] 做列運算化成 [I | B⁻¹]〔L7 p16–17〕

5. 完整實戰案例（FE Q4）
  【題目】
    Maximize z = 3x₁ + 5x₂ + 3x₃
    Subject to:
      x₁ + 2x₂ + x₃ ≤ 8
      2x₁ + x₂ + 3x₃ ≤ 10
      x₁ + x₂ + x₃ ≤ 6
      x₁, x₂, x₃ ≥ 0
    使用 revised simplex 與 Bland's rule。

  【題目辨識】題目指定 revised simplex 與 Bland → TOPIC 12。

  【初始設定】
    加 slack s₄、s₅、s₆，變數順序為 (x₁, x₂, x₃, s₄, s₅, s₆)。
    a₁ = (1,2,1)，a₂ = (2,1,1)，a₃ = (1,3,1)；slack 的欄是單位向量 e₁、e₂、e₃。
    b = (8,10,6)，c = (3,5,3,0,0,0)。
    J_B = (s₄, s₅, s₆)，B⁻¹ = I，x_B = (8, 10, 6)。

  【Iteration 1】
    c_B = (0,0,0) → y = (0,0,0)
    c̄₁ = 3，c̄₂ = 5，c̄₃ = 3，全部 > 0
    Bland：下標最小者是 x₁，所以 x₁ 進入（不是 c̄ 最大的 x₂）
    d = B⁻¹a₁ = (1, 2, 1)
    Ratio：8/1 = 8，10/2 = 5，6/1 = 6 → t = 5，s₅ 離開（位置 r = 2）
    x_B 更新：
      s₄ = 8 − 1·5 = 3
      x₁ = 5
      s₆ = 6 − 1·5 = 1
    J_B = (s₄, x₁, s₆)
    B⁻¹ 更新：
      R₂ ← R₂/2
      R₁ ← R₁ − 1·R₂
      R₃ ← R₃ − 1·R₂
      B⁻¹ = [ 1  −1/2  0 ]
            [ 0   1/2  0 ]
            [ 0  −1/2  1 ]
    z = 0 + 3·5 = 15

  【Iteration 2】
    c_B = (0, 3, 0)
    y = c_Bᵀ B⁻¹ = 3 × (B⁻¹ 的第 2 列) = (0, 3/2, 0)
    c̄₂ = 5 − (0·2 + 3/2·1 + 0·1) = 7/2 > 0
    c̄₃ = 3 − (3/2)·3 = −3/2
    c̄_s₅ = −3/2
    → 只有 x₂ 可以進入
    d = B⁻¹a₂：
      第 1 個分量：2 − 1/2 = 3/2
      第 2 個分量：1/2
      第 3 個分量：−1/2 + 1 = 1/2
      → d = (3/2, 1/2, 1/2)
    Ratio：
      s₄：3 / (3/2) = 2
      x₁：5 / (1/2) = 10
      s₆：1 / (1/2) = 2
    s₄ 與 s₆ 平手，依 Bland 選下標較小的 s₄ 離開（r = 1），t = 2
    x_B 更新：
      x₂ = 2
      x₁ = 5 − (1/2)·2 = 4
      s₆ = 1 − (1/2)·2 = 0　← 退化，屬正常現象
    J_B = (x₂, x₁, s₆)
    B⁻¹ 更新：
      R₁ ← (2/3)R₁ = (2/3, −1/3, 0)
      R₂ ← R₂ − (1/2)R₁ = (−1/3, 2/3, 0)
      R₃ ← R₃ − (1/2)R₁ = (−1/3, −1/3, 1)
      B⁻¹ = [  2/3  −1/3  0 ]
            [ −1/3   2/3  0 ]
            [ −1/3  −1/3  1 ]
    z = 15 + (7/2)·2 = 22

  【Iteration 3】
    c_B = (5, 3, 0)
    y = 5·(2/3, −1/3, 0) + 3·(−1/3, 2/3, 0) = (7/3, 1/3, 0)
    c̄₃ = 3 − (7/3 + 3·1/3 + 1/3) = 3 − 11/3 = −1/3
    c̄_s₄ = −7/3
    c̄_s₅ = −1/3
    → 全部 ≤ 0，已達最優

  【最終答案】
    J_B = (x₂, x₁, s₆)
    (x₁*, x₂*, x₃*) = (4, 2, 0)，s₆ = 0
    z* = 3·4 + 5·2 = 22

  【答案驗證】
    • B = [a₂ a₁ e₃] = [[2,1,0],[1,2,0],[1,1,1]]，乘上 B⁻¹ 得到 I ✓
    • 對偶檢查：y = (7/3, 1/3, 0) ≥ 0，bᵀy = 56/3 + 10/3 = 22 = z* ✓
    • 代回原約束：4 + 4 = 8 ✓，8 + 2 = 10 ✓，4 + 2 = 6 ✓
    • LP solver 的結果相同。

  【常見錯誤】
    • 第一步選 c̄ 最大的 x₂，違反 Bland。
    • 平手時沒有比較下標。
    • c_B 的順序沒有跟著 J_B 的位置。
    • 更新 B⁻¹ 時，「原本的 R₁」和「縮放後的 R₁」混用。

  【通用規則】每次迭代固定照 y → c̄ → 進入 → d → ratio → 離開 → 更新 x_B 與 B⁻¹ 的順序寫；B⁻¹ 永遠用列運算來更新。

  補充案例（T7 Q4，椅子與桌子，largest coefficient rule）
    三次迭代得到 J_B = {x₂, s₂, x₁}，x* = (4 張椅子, 5 張桌子)，z* = 370，y = (20, 0, 10)。

6. 常見錯誤與答案驗證
  • y 寫成行向量，或寫成 B⁻¹c_B（順序錯）。
  • 驗證：
    - B⁻¹ 乘上原本某一個基本欄，應該得到單位向量。
    - 最後 bᵀy = z*。

7. 考試速查
  • 停止條件：所有 c̄ ≤ 0（max）→ 最優；所有 dᵢ ≤ 0 → unbounded。
  • 最容易漏掉的步驟：寫出 Bland 的理由、平手的處理方式、B⁻¹ 的列運算。
  • 一句話：只維護 B⁻¹，用 y 判斷誰進入、用 d 判斷誰離開，再對 B⁻¹ 做讓 d 變成單位向量的列運算。

TOPIC 13：寫 dual（SIF 標準形式）★ FE Q1(a)(i)
==================================================

1. 題型辨識
  • 題目長相："Write down the dual of (P)"、"using y₁, …, yₘ as the dual variables"。
  • 結構：(P) 是 max，所有約束都是 ≤，所有變數 x ≥ 0。只要有一項不符合，就改用 TOPIC 14。

2. 解題邏輯
  • 給每條主約束一個乘數 yᵢ ≥ 0，把各約束相加，使左邊的每個係數都 ≥ cⱼ。這樣右邊 Σbᵢyᵢ 就是目標值的上界。
    dual 就是「找最小的上界」。〔L8 p17–21、p29〕
  • 對應關係：每條主約束對應一個對偶變數；每個主變數對應一條對偶約束。

3. 解題 SOP（六條規則，L8 p30）
  Step 1　每條主約束 i 設一個對偶變數 yᵢ。
  Step 2　dual 目標：min Σ bᵢyᵢ（係數用主問題的 RHS）。
  Step 3　第 j 條對偶約束：a₁ⱼy₁ + … + aₘⱼyₘ ≥ cⱼ。
          係數用 A 的第 j「欄」，也就是轉置。
  Step 4　所有 yᵢ ≥ 0。
  Step 5　檢查個數：對偶約束數 = 主變數數；對偶變數數 = 主約束數。

4. 重要公式
  (P) max cᵀx　s.t.　Ax ≤ b,　x ≥ 0
  (D) min bᵀy　s.t.　Aᵀy ≥ c,　y ≥ 0

5. 完整實戰案例（FE Q1(a)(i)）
  【題目】
    Max 2x₁ + 2x₂ + 4x₃
    s.t.
      9x₁ + x₂ ≤ 4
      x₁ + x₃ ≤ 3
      x₂ + 2x₃ ≤ 5
      x ≥ 0
  【辨識】max、全部 ≤、x ≥ 0 → 屬於 SIF，用 TOPIC 13。
  【逐步】
    A 的各欄：
      x₁ 欄 = (9, 1, 0)
      x₂ 欄 = (1, 0, 1)
      x₃ 欄 = (0, 1, 2)
    b = (4, 3, 5)，c = (2, 2, 4)
  【答案】
    Min 4y₁ + 3y₂ + 5y₃
    s.t.
      9y₁ + y₂ ≥ 2
      y₁ + y₃ ≥ 2
      y₂ + 2y₃ ≥ 4
      y₁, y₂, y₃ ≥ 0
  【驗證】3 條對偶約束對應 3 個主變數 ✓；3 個對偶變數對應 3 條主約束 ✓。
  【常見錯誤】直接照「列」抄寫，例如把第 1 條對偶約束寫成 9y₁ + y₂ + 0y₃，卻沒有逐欄核對。
  【通用規則】對偶約束 j 的係數 = A 的第 j 欄；兩邊的 b 和 c 互換位置。

6. 常見錯誤與答案驗證
  • 忘了轉置。
  • 不等號方向寫錯：SIF 的 dual 一律是 min 和 ≥。

7. 考試速查
  • 一句話：max ≤ 的 dual 是 min ≥；b 和 c 互換，A 轉置，y ≥ 0。

TOPIC 14：寫 dual（一般形式）
==================================================

1. 題型辨識
  • 題目長相："write down the dual of the LP in general form, stating the sign restriction of each dual variable and the type of each dual constraint"。
  • 結構：約束混合 ≤、≥、=；變數有 ≥0、≤0、free；可能是 min 問題。

2. 解題邏輯
  • 把問題轉成 SIF（≥ 乘以 −1、= 拆成兩條、free 拆成 x⁺ − x⁻、x ≤ 0 令 x' = −x），取 dual，再把轉換倒回來，就得到下面的對照表。〔L9 p17–22〕
  • 實際做題直接查表即可。

3. 解題 SOP
  Step 1　判斷 (P) 是 max 還是 min。(P) 為 max → (D) 為 min；反之亦然。
  Step 2　dual 目標係數用 b；對偶約束 j 的係數用 A 的第 j 欄，RHS 用 cⱼ。
  Step 3　依下表決定每個 yᵢ 的符號：

          (P) 為 max：
            約束 ≤ → yᵢ ≥ 0
            約束 ≥ → yᵢ ≤ 0
            約束 = → yᵢ free
          (P) 為 min：
            約束 ≥ → yᵢ ≥ 0
            約束 ≤ → yᵢ ≤ 0
            約束 = → yᵢ free

  Step 4　依下表決定每條對偶約束的型別：

          (P) 為 max：
            xⱼ ≥ 0 → 對偶約束 ≥ cⱼ
            xⱼ ≤ 0 → 對偶約束 ≤ cⱼ
            xⱼ free → 對偶約束 = cⱼ
          (P) 為 min：
            xⱼ ≥ 0 → 對偶約束 ≤ cⱼ
            xⱼ ≤ 0 → 對偶約束 ≥ cⱼ
            xⱼ free → 對偶約束 = cⱼ

  Step 5　每個 y 都標上符號，每條對偶約束都標上型別。

4. 重要公式（記憶口訣）
  • 自然配對對自然配對：
    max 的「≤ 約束、x ≥ 0」對應 min 的「y ≥ 0、≥ 約束」。
  • 不自然的配對就反號（≤0 或方向相反）。
  • 等式對 free。

5. 完整實戰案例
  【題目 A，T9 Q5，min 問題】
    Min 2x₁ − x₂ + 4x₃
    s.t.
      2x₁ − x₂ − x₃ ≥ 1
      2x₁ + 3x₂ + 2x₃ ≤ 3
      −x₂ − 2x₃ = −3
    變數：x₁ ≥ 0，x₂ ≤ 0，x₃ free
  【辨識】min 問題，約束與變數的型別混合 → 用 TOPIC 14。
  【逐步】
    (P) 為 min，所以 (D) 為 max，目標 = y₁ + 3y₂ − 3y₃
    約束 1 為 ≥ → y₁ ≥ 0
    約束 2 為 ≤ → y₂ ≤ 0
    約束 3 為 = → y₃ free
    x₁ ≥ 0 → 第 1 欄 (2, 2, 0)：2y₁ + 2y₂ ≤ 2
    x₂ ≤ 0 → 第 2 欄 (−1, 3, −1)：−y₁ + 3y₂ − y₃ ≥ −1
    x₃ free → 第 3 欄 (−1, 2, −2)：−y₁ + 2y₂ − 2y₃ = 4
  【答案】
    Max y₁ + 3y₂ − 3y₃
    s.t.
      2y₁ + 2y₂ ≤ 2
      −y₁ + 3y₂ − y₃ ≥ −1
      −y₁ + 2y₂ − 2y₃ = 4
    y₁ ≥ 0，y₂ ≤ 0，y₃ free
  【驗證】
    取 x* = (1, −1, 2)、y* = (2, −1, −4)：兩者各自可行，目標值都是 11 → 兩者都最優（LP solver 確認 11）。

  【題目 B，T9 Q2，max 問題】
    約束為 (=, ≤, =)，x₁, x₃, x₄ ≥ 0，x₂ free
    → y₁ free、y₂ ≥ 0、y₃ free
    → 對偶約束依序為 ≥、=、≥、≥（x₂ 那一條是等式）
  【常見錯誤】min 問題直接套用 max 的對照表。
  【通用規則】先確認 (P) 是 max 還是 min，再查對應的那一組表。

6. 常見錯誤與答案驗證
  • 驗證方法：拿一組已知的主問題可行解和對偶可行解，檢查 weak duality 的方向是否正確：
    max 的 (P)：cᵀx ≤ bᵀy；min 的 (P)：cᵀx ≥ bᵀy。

7. 考試速查
  • 一句話：約束的型別決定對偶變數的符號，變數的符號決定對偶約束的型別；min 問題整組反過來。

TOPIC 15：證明 weak duality、寫 C.S. 條件、C.S. 恆等式 ★ FE Q1(a)(ii)(iii)
==================================================

1. 題型辨識
  • 題目長相：
    - "Let x̄ be feasible for (P) with objective z_P and ȳ feasible for the dual with objective z_D. Prove z_P ≤ z_D."
    - "Write down the complementary slackness conditions."
    - "Verify the identity bᵀȳ − cᵀx̄ = Σȳᵢs̄ᵢ + Σv̄ⱼx̄ⱼ."

2. 解題邏輯
  • Weak duality 證明分兩段：
    - 用「對偶可行 + x ≥ 0」把 cᵀx 放大成 Σ(Aᵀy)ⱼxⱼ。
    - 重新分組後，用「主可行 + y ≥ 0」再放大成 bᵀy。〔L8 p25–27〕
  • C.S. 條件：當兩端相等時，鏈中每一個 ≤ 都必須是等號，於是每一項乘積都等於 0。〔L8 p36–39〕

3. 解題 SOP
  【證明 weak duality】
    Step 1　寫出 z_P = Σ cⱼx̄ⱼ。
    Step 2　因為 x̄ⱼ ≥ 0 且 Σᵢ aᵢⱼȳᵢ ≥ cⱼ（對偶可行）：
            z_P ≤ Σⱼ (Σᵢ aᵢⱼȳᵢ) x̄ⱼ
    Step 3　交換求和順序（重新分組）：
            = Σᵢ (Σⱼ aᵢⱼx̄ⱼ) ȳᵢ
    Step 4　因為 ȳᵢ ≥ 0 且 Σⱼ aᵢⱼx̄ⱼ ≤ bᵢ（主可行）：
            ≤ Σ bᵢȳᵢ = z_D
    Step 5　每一個 ≤ 都要註明是用了哪一個條件。
  【寫 C.S. 條件】
    Step 1　主問題 slack：sᵢ = bᵢ − Σⱼ aᵢⱼxⱼ
    Step 2　對偶 slack：vⱼ = Σᵢ aᵢⱼyᵢ − cⱼ
    Step 3　寫出 m 條 sᵢ·yᵢ = 0 以及 n 條 vⱼ·xⱼ = 0
  【驗證恆等式】
    把六個乘積逐一算出並相加，應該等於 bᵀȳ − cᵀx̄（T8 Q4）。

4. 重要公式
  • bᵀȳ − cᵀx̄ = Σᵢ ȳᵢ(bᵢ − Σⱼ aᵢⱼx̄ⱼ) + Σⱼ (Σᵢ ȳᵢaᵢⱼ − cⱼ) x̄ⱼ
    （右邊展開後，中間兩個雙重和互相抵消）
  • 兩者都可行時：兩者都最優 ⇔ 所有乘積都等於 0。〔L8 p39〕

5. 完整實戰案例（FE Q1(a)(ii)(iii)）
  【題目】(P)、(D) 同 TOPIC 13。
  【(ii) 證明】
    z_P = 2x̄₁ + 2x̄₂ + 4x̄₃
        ≤ (9ȳ₁ + ȳ₂)x̄₁ + (ȳ₁ + ȳ₃)x̄₂ + (ȳ₂ + 2ȳ₃)x̄₃
          [x̄ ≥ 0，且 ȳ 滿足三條對偶約束]
        = (9x̄₁ + x̄₂)ȳ₁ + (x̄₁ + x̄₃)ȳ₂ + (x̄₂ + 2x̄₃)ȳ₃
          [重新分組]
        ≤ 4ȳ₁ + 3ȳ₂ + 5ȳ₃ = z_D
          [ȳ ≥ 0，且 x̄ 滿足三條主約束]　∎
  【(iii) C.S. 條件】
    (4 − 9x₁ − x₂)·y₁ = 0
    (3 − x₁ − x₃)·y₂ = 0
    (5 − x₂ − 2x₃)·y₃ = 0
    (9y₁ + y₂ − 2)·x₁ = 0
    (y₁ + y₃ − 2)·x₂ = 0
    (y₂ + 2y₃ − 4)·x₃ = 0
  【驗證】把 x* = (4/9, 0, 5/2)、y* = (2/9, 0, 2) 代入，六個乘積都是 0 ✓（見 TOPIC 16）。
  【常見錯誤】沒有寫出每一個 ≤ 的理由；條件寫錯，例如寫成 sᵢ·xᵢ。
  【通用規則】證明的骨架是：對偶可行乘 x、重新分組、主可行乘 y。

  補充案例（T8 Q4：恆等式的數值驗證）
    x̄ = (2, 1, 1)，s̄ = (3, 2, 6)，cᵀx̄ = 21
    ȳ = (1, 3, 1)，v̄ = (2, 9, 4)，bᵀȳ = 53
    Σȳᵢs̄ᵢ = 3 + 6 + 6 = 15；Σv̄ⱼx̄ⱼ = 4 + 9 + 4 = 17
    15 + 17 = 32 = 53 − 21 ✓

6. 常見錯誤與答案驗證
  • 主問題是等式約束時，y 為 free，證明的第一步會變成等號（T8 Q2）。

7. 考試速查
  • 一句話：weak duality 是兩次放大加一次重新分組；C.S. 是每個「slack × 對應變數」都等於 0。

==================================================
TOPIC 16：用 C.S. 判斷 x* 是否最優 ★ FE Q1(a)(iv)
==================================================

1. 題型辨識
  • 題目長相：
    - "Determine, using complementary slackness, whether x* is optimal"
    - "use the Complementary Slackness Theorem to determine whether … is optimal; if it is, give a simple algebraic proof"
  • 結構：題目給一個候選解 x*，要求不用 simplex 判斷它是否最優。
  • 與 TOPIC 17 的差別：TOPIC 17 的目標係數 c 是未知參數。

2. 解題邏輯
  • C.S. Theorem：可行的 x* 是最優解 ⇔ 存在對偶可行的 y*，使 (x*, y*) 滿足 C.S.〔L9 p6–8〕
  • 用 x* 的資訊（哪些 sᵢ > 0、哪些 xⱼ > 0）可以把 y* 的方程組寫出來。
    若解唯一，只要檢查它是否對偶可行即可下結論。〔L9 p13〕
  • 若不是最優：yᵢ < 0 代表把約束 i 放鬆，目標會變好（T9 Q4）。

3. 解題 SOP（三步，L9 p9）
  Step 0　寫出 dual（TOPIC 13 或 14）。
  Step 1　主問題可行性：逐條代入。
          有任何一條不成立 → 不是最優，停止。
          每條標出 tight 或 slack（寫出 slack 值）。
  Step 2　用 C.S. 列出方程式：
          sᵢ > 0 → yᵢ = 0
          xⱼ* > 0 → 第 j 條對偶約束取等號
          解出 y*。
  Step 3　對偶可行性：
          y* 的符號正確（SIF 時 ≥ 0）；
          而且「其餘」的對偶約束（對應 xⱼ* = 0 的那幾條）也要成立。
          全部成立 → x* 最優；最優值 = cᵀx* = bᵀy*。
          有任何不成立，而且 y* 是唯一解 → x* 不是最優。
  【附加：代數證明（T9 Q1）】
    用 y* 當乘數把主約束相加，得到 (組合後的左邊) ≤ bᵀy*。
    再說明 cᵀx ≤ (組合後的左邊)：兩邊係數的差乘上 x ≥ 0。
  【附加：非最優時的改進（T9 Q4）】
    找出 yᵢ < 0 的約束 i；
    保持其他 tight 約束不變，解 Ad = −eᵢ；
    沿方向 d 走，直到某個變數變成 0；
    對新的點重新做一次三步檢驗。

4. 重要公式
  • C.S. 條件：yᵢ·sᵢ = 0，vⱼ·xⱼ = 0
  • 改進方向的變化率：cᵀd = −yᵢ > 0（當 yᵢ < 0）

5. 完整實戰案例（FE Q1(a)(iv)）
  【題目】(P) 同 TOPIC 13。判斷 x* = (4/9, 0, 5/2) 是否為最優解。
  【辨識】有候選解，題目要求用 C.S. → TOPIC 16。
  【Step 1】
    9·(4/9) + 0 = 4 → tight（s₁ = 0）
    4/9 + 5/2 = 53/18 < 3 → slack，s₂ = 1/18
    0 + 2·(5/2) = 5 → tight（s₃ = 0）
    x* ≥ 0 ✓ → x* 可行
  【Step 2】
    s₂ > 0 → y₂ = 0
    x₁* > 0 → 9y₁ + y₂ = 2 → y₁ = 2/9
    x₃* > 0 → y₂ + 2y₃ = 4 → y₃ = 2
    → y* = (2/9, 0, 2)
  【Step 3】
    y* ≥ 0 ✓
    第 2 條對偶約束（x₂ = 0，Step 2 沒有用到）：y₁ + y₃ = 2/9 + 2 = 20/9 ≥ 2 ✓
  【結論】依 Complementary Slackness Theorem，x* 是最優解。Z* = 2·(4/9) + 4·(5/2) = 98/9。
  【驗證】bᵀy* = 4·(2/9) + 5·2 = 98/9 = cᵀx* ✓；LP solver 的主問題與對偶問題都得到 10.8889。
  【常見錯誤】
    • 漏了 Step 3 中第 2 條對偶約束的檢查。
    • 把 53/18 誤判為 tight。

  補充案例 A（T9 Q1：最優，加代數證明）
    x* = (0, 2, 3, 1)
    約束值依序為 −3、6、0 → 前兩條 tight，第 3 條 slack 1 → y₃ = 0
    x₂, x₃, x₄ > 0 → 三條對偶約束取等號 → y* = (1, 1, 0)
    第 1 條對偶約束：4 ≥ 3 ✓ → x* 最優
    代數證明：第 1 條主約束 + 第 2 條主約束 → 4x₁ + 6x₂ − x₃ − 6x₄ ≤ 3
              又因為 x₁ ≥ 0，3x₁ ≤ 4x₁，所以 3x₁ + 6x₂ − x₃ − 6x₄ ≤ 3 = cᵀx*

  補充案例 B（T9 Q4：不是最優，並加以改進）
    x̄ = (3, 3, 1)，三條約束都 tight，三個變數都 > 0
    → 三條對偶約束都取等號 → y = (−3/4, 1/4, 5/4)
    y₁ < 0 → 不是對偶可行 → x̄ 不是最優
    改進：解 Ad = −e₁，得 d = (−1/2, 3/8, 3/8)，cᵀd = 3/4 > 0
          沿 d 走到 x₁ = 0（t = 6）→ x* = (0, 21/4, 13/4)，目標 43/2
          重新檢驗：y* = (0, 1, 1/2) 對偶可行 → 新的點是最優解

  【通用規則】有正值的變數 → 對應的對偶約束取等號；有 slack 的主約束 → 對應的 y = 0；最後一定要回頭檢查剩下的對偶約束。

6. 常見錯誤與答案驗證
  • xⱼ = 0 時，什麼都不能推出來（C.S. 只說「至少一個為 0」）。
  • 驗證：cᵀx* 必須等於 bᵀy*。

7. 考試速查
  • 結論句："By the Complementary Slackness Theorem, x* is (not) optimal."
  • 一句話：主可行 → 用 C.S. 解出 y → 檢查 y 是否對偶可行。

TOPIC 17：參數化目標：何時給定解為最優 ★ FE Q1(b)
==================================================

1. 題型辨識
  • 題目長相："determine the condition on c₁, c₂, c₃ to guarantee that x̄ is an optimal solution"。
  • 結構：目標係數是符號，x̄ 已經給定；題目通常要求用 C.S. Theorem。
  • 與 TOPIC 20、21 的差別：TOPIC 20、21 會給一個最優 basis 和 B⁻¹，只改其中一個係數；這裡所有係數都是參數，而且沒有 basis 資料。

2. 解題邏輯
  • x̄ 最優 ⇔ 存在對偶可行的 y 與 x̄ 滿足 C.S.
  • 先用 C.S. 把 y 用 c 表示出來，再要求它對偶可行。這些要求就是 c 要滿足的不等式。

3. 解題 SOP
  Step 1　寫出 dual，RHS 中保留 cⱼ 符號。
  Step 2　檢查 x̄ 是否可行，標出每條約束是 tight 還是 slack。
  Step 3　用 C.S.：slack 的約束 → yᵢ = 0；x̄ⱼ > 0 → 第 j 條對偶約束取等號。
  Step 4　用 c 解出 y(c)，並確認解是否唯一。
  Step 5　要求 y(c) ≥ 0，而且其餘的對偶約束（x̄ⱼ = 0 對應的）都成立。
  Step 6　整理成 c 的條件，寫出答案。

4. 重要公式
  • 條件 = { y(c) ≥ 0 } ∩ { 對每個 x̄ⱼ = 0 的 j：(Aᵀy(c))ⱼ ≥ cⱼ }

5. 完整實戰案例（FE Q1(b)）
  【題目】
    Max c₁x₁ + c₂x₂ + c₃x₃
    s.t.
      x₁ + x₂ + x₃ ≤ 4
      2x₁ + x₂ ≤ 5
      x ≥ 0
    x̄ = (1, 3, 0)
  【Step 1】
    Dual：Min 4y₁ + 5y₂
    s.t. y₁ + 2y₂ ≥ c₁；y₁ + y₂ ≥ c₂；y₁ ≥ c₃；y ≥ 0
  【Step 2】
    1 + 3 + 0 = 4（tight）；2 + 3 = 5（tight）→ C.S. 不會強迫任何 y = 0
  【Step 3、4】
    x̄₁ > 0 → y₁ + 2y₂ = c₁
    x̄₂ > 0 → y₁ + y₂ = c₂
    兩式相減：y₂ = c₁ − c₂；代回：y₁ = 2c₂ − c₁（唯一解）
  【Step 5】
    y₂ ≥ 0 → c₁ − c₂ ≥ 0
    y₁ ≥ 0 → 2c₂ − c₁ ≥ 0
    第 3 條對偶約束（x̄₃ = 0）→ y₁ ≥ c₃ → 2c₂ − c₁ ≥ c₃
  【答案】c₂ ≤ c₁ ≤ 2c₂，而且 c₃ ≤ 2c₂ − c₁
  【驗證】隨機抽 4000 組整數 c，用 LP solver 檢查 x̄ 是否最優；結果與上面的條件完全一致，0 個反例。
  【常見錯誤】漏了 c₃ 的條件。x₃ = 0 那一條對偶約束仍然要成立。
  【通用規則】參數題和 TOPIC 16 是同一個流程，只是把數字換成符號；最後的對偶可行條件就是答案。

6. 常見錯誤與答案驗證
  • 驗證方法：取一組滿足條件的 c（例如 c = (3, 2, 0)）與一組不滿足的 c，各自代入檢查。

7. 考試速查
  • 一句話：用 C.S. 把 y 寫成 c 的函數，再要求 y 對偶可行。

TOPIC 18：Complementary basis／complementary basic solution
==================================================

1. 題型辨識
  • 題目長相：
    - "Write down the complementary basis and find the complementary basic solution determined by the basis {…}"
    - "Is the basis primal/dual feasible?"
    - "Compare the reduced costs with y and v."
  • 結構：題目給一個主問題的 augmented basis（包含 slack）。

2. 解題邏輯
  • 配對：xⱼ ↔ vⱼ（對偶 surplus），sᵢ ↔ yᵢ。〔L8 p47〕
  • 對偶基底 K_N = 和「主問題的非基本變數」配對的那些對偶變數。〔L8 p48、p55〕
  • 定理 (I)：K_N 一定是 dual 的 basis，而且 (x*, y*) 自動滿足 C.S.
    → 主問題目標值永遠等於對偶目標值。
  • 定理 (II)：y*ᵀ = c_Bᵀ B⁻¹；c̄ⱼ = −vⱼ；c̄_sᵢ = −yᵢ
    → 主問題最優（所有 c̄ ≤ 0）⇔ 對偶可行。〔L8 p60–63〕
  • 注意：兩邊目標值相等，並不代表兩邊都可行（T8 Q3）。

3. 解題 SOP
  Step 1　寫出 augmented primal：Ax + s = b；augmented dual：Aᵀy − v = c。
  Step 2　列出主問題的非基本變數，依配對得到 K_N。
  Step 3　不在 K_N 裡的對偶變數全部設為 0，解出 K_N 中的變數。
  Step 4　主問題的 basic solution：非基本變數設 0，解出 x_B 與 s_B。
  Step 5　判斷：
          x_B ≥ 0 → primal feasible
          (y, v) ≥ 0 → dual feasible
          兩者都成立 → 兩者都最優
  Step 6　（題目有問時）比較 c̄ⱼ = −vⱼ、c̄_sᵢ = −yᵢ。

4. 重要公式
  • y*ᵀ = c_Bᵀ B⁻¹，v = Aᵀy − c
  • bᵀy* = cᵀx*（對任何 basis 都成立）

5. 完整實戰案例（T8 Q5）
  【題目】
    Max 7x₁ + 6x₂ + 6x₃
    s.t.
      2x₁ + x₂ + 4x₃ ≤ 12
      x₁ + x₂ + 2x₃ ≤ 14
      x₁ + x₂ + 3x₃ ≤ 7
      x ≥ 0
    J_B = {x₁, x₂, s₂}
  【Step 1】
    Augmented dual：
      2y₁ + y₂ + y₃ − v₁ = 7
      y₁ + y₂ + y₃ − v₂ = 6
      4y₁ + 2y₂ + 3y₃ − v₃ = 6
      全部變數 ≥ 0
  【Step 4（主問題）】
    令 x₃ = s₁ = s₃ = 0：
      2x₁ + x₂ = 12
      x₁ + x₂ = 7
      → x₁ = 5，x₂ = 2；s₂ = 14 − 7 = 7
    → primal feasible
  【Step 2、3（對偶）】
    主問題非基本變數 = {x₃, s₁, s₃} → K_N = {v₃, y₁, y₃}
    令 v₁ = v₂ = y₂ = 0：
      2y₁ + y₃ = 7
      y₁ + y₃ = 6
      → y₁ = 1，y₃ = 5
      v₃ = 4·1 + 3·5 − 6 = 13
    → y = (1, 0, 5)，v = (0, 0, 13)，全部 ≥ 0 → dual feasible
  【Step 5】兩者都可行 → 兩者都最優，目標值 47 = 47
  【Step 6】
    c̄₃ = 6 − (4 + 0 + 15) = −13 = −v₃
    c̄_s₁ = −y₁ = −1
    c̄_s₃ = −y₃ = −5
  【驗證】LP solver 最優值 47，最優解 (5, 2, 0)。
  【常見錯誤】用主問題的「基本」變數去配對；K_N 應該配對的是「非基本」變數。

  補充案例（T8 Q3：兩邊都不可行，但目標值仍相等）
    主問題 s₂ = −21 → 不可行；對偶 v₂ = −4 → 不可行
    兩邊目標值都是 −4

6. 常見錯誤與答案驗證
  • 對偶 slack 的定義是 v = Aᵀy − c，不是 c − Aᵀy。

7. 考試速查
  • 一句話：主問題的非基本變數對應到 K_N；解出 y = c_Bᵀ B⁻¹；對偶可行等價於主問題最優。

TOPIC 19：Primal–dual 狀態判斷與 Farkas 不可行證明
==================================================

1. 題型辨識
  • 題目長相：
    - "determine the status of the primal and of its dual"
    - "show it is unbounded / infeasible"
    - "show that system (II) is solvable … deduce (I) is infeasible"
  • 結構：小型 LP，或是 Ax = b、Ax ≤ b 這類系統。

2. 解題邏輯
  • Primal–Dual Relation Theorem〔L9 p23–24〕：
    (1) P 有最優解 ⇔ D 有最優解，而且兩者最優值相等
    (2) P infeasible ⇒ D infeasible 或 unbounded
    (3) P unbounded ⇒ D infeasible
  • 可能出現的組合只有四種：
    （最優, 最優）、（不可行, 不可行）、（不可行, 無界）、（無界, 不可行）
  • Farkas（L9 p27–30；T9 Q7）：
    Ax ≤ b, x ≥ 0 無解 ⇔ ∃ l ≥ 0，Aᵀl ≥ 0，bᵀl < 0
    Ax = b, x ≥ 0 無解 ⇔ ∃ y（free），Aᵀy ≥ 0，bᵀy < 0

3. 解題 SOP
  Step 1　判斷 (P) 的狀態：
          證明 unbounded → 構造射線 x(t)，驗證它可行而且 Z → ∞
          證明 infeasible → 把約束組合出矛盾（例如相加得 0 ≤ −2），或找到 Farkas 證書
  Step 2　寫出 (D)，用同樣的方法判斷它的狀態。
  Step 3　用定理檢查兩邊狀態的組合是否合理。
  Step 4　Farkas 證明：
          找 y（可以試整數，或用原約束各列的組合）
          驗證 Aᵀy ≥ 0、bᵀy < 0
          推論：bᵀy = (Ax)ᵀy = xᵀ(Aᵀy) ≥ 0，與 bᵀy < 0 矛盾，所以 (I) 無解

4. 重要公式
  • 若 x 可行且 y 是證書：0 ≤ xᵀAᵀy = bᵀy < 0，矛盾

5. 完整實戰案例（T9 Q6、Q7）
  【題目 A，T9 Q6(a)】
    Max x₁ + x₂，s.t. x₁ − 2x₂ ≤ 2，−x₁ + x₂ ≤ 1，x ≥ 0
    射線 (t, t)：−t ≤ 2 ✓，0 ≤ 1 ✓ → Z = 2t → ∞ → P unbounded
    Dual：y₁ − y₂ ≥ 1，−2y₁ + y₂ ≥ 1；兩式相加得 −y₁ ≥ 2，與 y₁ ≥ 0 矛盾 → D infeasible
    符合定理第 (3) 條。

  【題目 B，T9 Q6(c)】
    Max x₁，s.t. x₁ − x₂ ≤ −1，−x₁ + x₂ ≤ −1
    兩式相加得 0 ≤ −2 → P infeasible
    對偶約束相加得 0 ≥ 1 → D infeasible
    → 兩邊都不可行。

  【題目 C，T9 Q7】
    A = [[2,1,3],[1,0,2]]，b = (1, 3)。證明 Ax = b, x ≥ 0 無解。
    取 y = (1, −1)：Aᵀy = (1, 1, 1) ≥ 0，bᵀy = −2 < 0 → 證書成立 → 無解
    直接驗證：第 1 列減第 2 列得 x₁ + x₂ + x₃ = −2，在 x ≥ 0 下不可能成立。

  【常見錯誤】看到 P infeasible，就斷定 D 一定 unbounded（反例：題目 B）。
  【通用規則】判斷狀態時一定要附上證據：unbounded 給射線，infeasible 給矛盾或證書，再用相容表檢查。

6. 常見錯誤與答案驗證
  • 證書 y 的符號要求：Ax = b 的版本 y 是 free；Ax ≤ b 的版本 l ≥ 0。

7. 考試速查
  • 一句話：最優對最優；P 無界則 D 不可行；P 不可行則 D 不可行或無界，每一個判斷都要附上證據。

PART VI　Sensitivity analysis
==================================================

【PART VI 共同前提】
  • 題目會給：最優基底 J_B、B⁻¹、x_B* = B⁻¹b、y = c_Bᵀ B⁻¹、各非基本變數的 c̄。
  • 判斷原基底是否仍最優，只看兩件事：
      primal feasible：x_B = B⁻¹b ≥ 0
      optimal：所有 c̄ⱼ = cⱼ − y·aⱼ ≤ 0（max 問題）
  • 改的是什麼，決定要檢查哪一件：〔L9 p42–56；T10 Q9〕
      改非基本變數的 cⱼ → 只影響 c̄ⱼ 這一個
      改基本變數的 cⱼ  → y 改變，所有非基本變數的 c̄ 都要重算
      改 bᵢ             → 只影響 x_B，y 與 c̄ 不變
      新增變數          → 只要算新變數的 c̄
  • 範圍內：基底不變，最優解（或只有 x_B）依公式更新。
    範圍外：用 revised simplex 從原基底繼續做（TOPIC 23）。

TOPIC 20：非基本變數的目標係數範圍
==================================================

1. 題型辨識
  • 題目長相："For what range of c₂ does the current basis remain optimal?"，而 x₂ 不在 J_B 裡。
  • 常見追問："If c₂ = 10, what is the optimal solution?"、"Interpret the reduced cost."

2. 解題邏輯
  • xⱼ 不在基底中 → c_B 沒變 → y 沒變 → 其他 c̄ 都沒變。
  • 唯一改變的是 c̄ⱼ = cⱼ − y·aⱼ。要求它 ≤ 0 即可。
  • 經濟意義：y·aⱼ 是「生產一單位 xⱼ 所用掉資源的影子價值」，也就是損益兩平價格。
    cⱼ 低於這個價格就不值得生產。〔L9 p42–47〕

3. 解題 SOP
  Step 1　確認 xⱼ 是非基本變數。
  Step 2　算 y·aⱼ（y 題目通常會給；沒給就算 c_Bᵀ B⁻¹）。
  Step 3　條件：cⱼ ≤ y·aⱼ。
  Step 4　範圍內：最優解 x* 不變，最優值不變（因為 xⱼ* = 0）。
  Step 5　範圍外：c̄ⱼ > 0，xⱼ 進入，轉 TOPIC 23。

4. 重要公式
  • c̄ⱼ(cⱼ) = cⱼ − y·aⱼ ≤ 0 ⇔ cⱼ ≤ y·aⱼ
  • 範圍：(−∞, y·aⱼ]

5. 完整實戰案例（T9 Q8）
  【題目】
    A = [[0, 2, 4, 1], [2, −1, 3, −2], [0, 3, 0, 1]]
    b = (5, 4, 9)，c = (3, 4, −2, 3)
    最優基底 J_B = {x₄, x₁, x₇}，x_B* = (5, 7, 4)，y = (6, 3/2, 0)
    (a) 求 c₂、c₃ 的範圍；(b) c₂ = 10 與 c₂ = 11 時怎樣；(c) 解釋 c̄₂。
  【辨識】x₂、x₃ 不在 J_B → TOPIC 20。
  【逐步】
    a₂ = (2, −1, 3)：y·a₂ = 6·2 + (3/2)·(−1) + 0·3 = 12 − 3/2 = 21/2
      → c₂ ≤ 21/2
    a₃ = (4, 3, 0)：y·a₃ = 24 + 9/2 = 57/2
      → c₃ ≤ 57/2
    c₂ = 10 ≤ 21/2 → 基底仍最優，x* = (7, 0, 0, 5)，Z* = 3·7 + 3·5 = 36
    c₂ = 11 > 21/2 → c̄₂ = 1/2 > 0 → 原基底不再最優
  【經濟解釋】
    x₂ 每單位收益 4；用掉的資源按影子價格計算值 21/2
      資源 1：2 單位 × 6 = 12
      資源 2：釋放 1 單位 × 3/2 → 扣 3/2
      資源 3：影子價格 0
    淨值 4 − 21/2 = −13/2 = c̄₂
  【驗證】LP solver：c₂ = 10 時 36，c₂ = 10.5 時 36，c₂ = 11 時 37.25（變大，表示基底換了）。
  【常見錯誤】忘了 aⱼ 中的負係數，把 y·a₂ 算成 12 + 3/2。
  【通用規則】非基本變數：只看自己的 c̄；範圍上界就是 y·aⱼ，沒有下界。

  補充案例（T9 Q3、T10 Q1）
    y = (1/4, 1/2, 0)，a₁ = (3, 8, 7)
    y·a₁ = 3/4 + 4 = 19/4 → c₁ ≤ 19/4

6. 常見錯誤與答案驗證
  • 驗證：取範圍內的一個值和範圍外的一個值，分別看 c̄ⱼ 的正負。
  • min 問題時方向相反（c̄ⱼ ≥ 0 才最優）。本課程題目都是 max。

7. 考試速查
  • 一句話：非基本變數 → cⱼ ≤ y·aⱼ；其餘全部不變。

TOPIC 21：基本變數的目標係數範圍
==================================================

1. 題型辨識
  • 題目長相："Find the range of c₃ over which the current basis remains optimal"，而 x₃ 在 J_B 裡。
  • 追問常是："what is the new optimal value?"

2. 解題邏輯
  • xₖ 在基底中 → c_B 改變 → y = c_Bᵀ B⁻¹ 改變 → 每一個非基本變數的 c̄ 都改變。
  • 每個 c̄ⱼ 都是 cₖ 的一次函數；要求全部 ≤ 0，取交集。〔L9 p48–51〕
  • x_B = B⁻¹b 不受影響，可行性自動成立。

3. 解題 SOP
  Step 1　c_B 中把 cₖ 換成符號（注意它在 J_B 中的位置）。
  Step 2　y(cₖ) = c_Bᵀ B⁻¹（B⁻¹ 的「列」乘上係數）。
  Step 3　對每個非基本變數 j（包括 slack）：c̄ⱼ(cₖ) = cⱼ − y(cₖ)·aⱼ。
          slack sᵢ 的欄是 eᵢ，所以 c̄_sᵢ = −yᵢ。
  Step 4　每條 c̄ⱼ ≤ 0 解出 cₖ 的上下界，取交集。
  Step 5　範圍內：x* 不變；Z* = Z_old + Δcₖ·xₖ*。

4. 重要公式
  • y(cₖ) = y_old + Δcₖ·(B⁻¹ 中對應 xₖ 的那一列)
  • c̄ⱼ(cₖ) = c̄ⱼ,old − Δcₖ·(B⁻¹aⱼ)ᵣ，r 為 xₖ 在 J_B 中的位置
  • Z* = Z_old + Δcₖ·xₖ*

5. 完整實戰案例（T10 Q3）
  【題目】
    A = [[−3, 1, −1, −7], [2, −6, 0, −2], [1, −6, 2, 0]]
    b = (3, 1, 1)，c = (1, −9, 1, −8)
    最優基底 J_B = {x₅, x₁, x₃}，x_B* = (19/4, 1/2, 1/4)
    B⁻¹ =
      │ 1    5/4    1/2 │
      │ 0    1/2    0   │
      │ 0   −1/4    1/2 │
    求 c₃ 的範圍。
  【辨識】x₃ ∈ J_B → TOPIC 21。
  【逐步】
    c_B = (0, 1, c₃)
    y = 0·(第 1 列) + 1·(第 2 列) + c₃·(第 3 列)
      = (0, 1/2, 0) + c₃·(0, −1/4, 1/2)
      = (0, 1/2 − c₃/4, c₃/2)
    非基本變數：x₂, x₄, x₆（slack 2）, x₇（slack 3）
    c̄₂ = −9 − y·(1, −6, −6) = −9 − [−6(1/2 − c₃/4) − 6(c₃/2)] = 3c₃/2 − 6 ≤ 0 → c₃ ≤ 4
    c̄₄ = −8 − y·(−7, −2, 0) = −8 + 2(1/2 − c₃/4) = −c₃/2 − 7 ≤ 0 → c₃ ≥ −14
    c̄₆ = −y₂ = c₃/4 − 1/2 ≤ 0 → c₃ ≤ 2
    c̄₇ = −y₃ = −c₃/2 ≤ 0 → c₃ ≥ 0
  【答案】c₃ ∈ [0, 2]
  【驗證】
    c₃ = 1 代回：y = (0, 1/4, 1/2)，與題目給的一致 ✓
    LP solver（c₃ = 1）最優值 0.75 = 1·(1/2) + 1·(1/4) ✓
  【常見錯誤】只檢查 x₂、x₄，漏掉 slack 變數 x₆、x₇（本題最緊的兩條正好都來自 slack）。
  【通用規則】基本變數：四條（所有非基本變數）都要重算，包括 slack。

  補充案例（T10 Q10(b)，麵包店）
    max 60x₁ + 60x₂ + 40x₃
    約束：x₁ + 3x₂ + x₃ ≤ 36；x₁ + 2x₂ + 2x₃ ≤ 20；3x₁ + 2x₂ + 2x₃ ≤ 36
    J_B = {x₄, x₂, x₁}，x_B* = (10, 6, 8)
    B⁻¹ =
      │ 1   −7/4    1/4 │
      │ 0    3/4   −1/4 │
      │ 0   −1/2    1/2 │
    c_B = (0, 60, c₁) → y = (0, 45 − c₁/2, c₁/2 − 15)
    c̄₅ = −y₂ = c₁/2 − 45 ≤ 0 → c₁ ≤ 90
    c̄₆ = −y₃ = 15 − c₁/2 ≤ 0 → c₁ ≥ 30
    c̄₃ = 40 − y·(1, 2, 2) = 40 − 60 = −20（與 c₁ 無關）
    → c₁ ∈ [30, 90]

6. 常見錯誤與答案驗證
  • 驗證：把原來的 cₖ 代入 y(cₖ)，必須得到題目給的 y。
  • 範圍必定包含原來的 cₖ。

7. 考試速查
  • 一句話：基本變數 → y 跟著變 → 所有非基本 c̄（含 slack）都重算，取交集。

TOPIC 22：右端常數 b 的範圍與 shadow price
==================================================

1. 題型辨識
  • 題目長相：
    - "Find the range of b₃ for which the current basis remains optimal"
    - "What are the shadow prices? Interpret."
    - "If b₂ decreases to 2, what is the new optimal value?"
    - "Is it worth buying extra labour at $12 per hour?"

2. 解題邏輯
  • 改 b 不影響 y 與 c̄（它們只和 c、A、B 有關），最優性自動成立。
  • 只要檢查 x_B = B⁻¹b ≥ 0。〔L9 p52–56〕
  • 在範圍內：Z*(b) = yᵀb，所以 ∂Z*/∂bᵢ = yᵢ，這就是 shadow price。
  • 約束沒有 tight（slack 在基底中）→ shadow price = 0。

3. 解題 SOP
  Step 1　x_B(bᵢ) = B⁻¹b，把 bᵢ 換成符號；等價於 x_B* + Δbᵢ·(B⁻¹ 的第 i「欄」)。
  Step 2　每個分量 ≥ 0，解出 bᵢ 的範圍，取交集。
  Step 3　範圍內：新解 x_B = B⁻¹b_new，新最優值 Z* + yᵢΔbᵢ。
  Step 4　購買資源的判斷：單價 < yᵢ 才值得買，最多買到範圍上界。
          淨增益 = (yᵢ − 單價) × 購買量。
  Step 5　同時改多個 b：要直接算 B⁻¹b_new ≥ 0；個別都在範圍內不代表一起改也可行。

4. 重要公式
  • x_B(b) = B⁻¹b ≥ 0
  • Z*(b) = yᵀb（只在基底不變時成立）
  • shadow price yᵢ = c_Bᵀ B⁻¹ 的第 i 個分量；slack 在基底中 ⇒ yᵢ = 0

5. 完整實戰案例（T10 Q5、Q7）
  【題目】
    A = [[−7, 6, 0, −3], [4, −1, −1, 4], [5, −4, −2, 3]]
    b = (5, 3, 1)，c = (−2, −3, −2, 7)
    J_B = {x₅, x₃, x₄}，x_B* = (8, 1, 1)，y = (0, 8/5, 1/5)，Z* = 5
    B⁻¹ =
      │ 1    6/5   −3/5 │
      │ 0    3/5   −4/5 │
      │ 0    2/5   −1/5 │
  【(Q5) b₃ 的範圍】
    x_B = B⁻¹(5, 3, b₃)
        = (5 + 18/5 − 3b₃/5, 9/5 − 4b₃/5, 6/5 − b₃/5)
        = (43/5 − 3b₃/5, 9/5 − 4b₃/5, 6/5 − b₃/5)
    ≥ 0 → b₃ ≤ 43/3，b₃ ≤ 9/4，b₃ ≤ 6
    答案：b₃ ∈ (−∞, 9/4]
  【(Q7a) shadow price】y = (0, 8/5, 1/5)；約束 1 的 slack x₅ = 8 在基底中 → y₁ = 0。
  【(Q7b) b₂ 的範圍】
    x_B = (6b₂/5 + 22/5, 3b₂/5 − 4/5, 2b₂/5 − 1/5) ≥ 0
    → b₂ ≥ −11/3，b₂ ≥ 4/3，b₂ ≥ 1/2 → b₂ ≥ 4/3
  【(Q7c) 單獨改】
    b₂：3 → 2（在範圍內）→ x_B = (34/5, 2/5, 3/5) ≥ 0，Z = 5 − 8/5 = 17/5 ✓
    b₃：1 → 2（在範圍內）→ x_B = (37/5, 1/5, 4/5) ≥ 0，Z = 5 + 1/5 = 26/5 ✓
  【(Q7d) 同時改】
    b = (5, 2, 2) → x_B = (31/5, −2/5, 3/5)，x₃ < 0 → 原基底不可行
    shadow price 預測 3.6，但 LP solver 的實際最優值是 3.5
  【驗證】LP solver：b₃ = 9/4 時 5.25 = 5 + (1/5)(5/4) ✓；b₂ = 2 時 3.4 ✓；b₃ = 2 時 5.2 ✓
  【常見錯誤】用 B⁻¹ 的「列」去乘 Δbᵢ。應該用第 i「欄」。
  【通用規則】改 b 只看可行性；shadow price 只在範圍內有效。

  補充案例（T10 Q10(c)，麵包店人工時數 b₂）
    x_B = B⁻¹(36, b₂, 36) = (45 − 7b₂/4, 3b₂/4 − 9, 18 − b₂/2) ≥ 0
    → b₂ ≤ 180/7，b₂ ≥ 12，b₂ ≤ 36 → b₂ ∈ [12, 180/7]
    加班每小時 12 < y₂ = 15 → 值得買，最多買 180/7 − 20 = 40/7 小時
    淨增 (15 − 12)·40/7 = 120/7 ≈ 17.1
    若加 6 小時（b₂ = 26 > 180/7）：shadow price 預測 840 + 90 = 930，實際最優值 925.71

6. 常見錯誤與答案驗證
  • 驗證：範圍端點代入，必有一個 x_B 分量正好是 0。
  • 最優值的驗證：c_Bᵀ x_B 應等於 yᵀb。

7. 考試速查
  • 一句話：改 b 只檢查 B⁻¹b ≥ 0；範圍內 ΔZ = yᵢΔbᵢ；超出範圍不能用 shadow price。

TOPIC 23：新增變數，以及超出範圍後重新最佳化
==================================================

1. 題型辨識
  • 題目長相：
    - "A new product x₀ with column a₀ and profit c₀ is introduced. Is it worth producing?"
    - "For what c₀ is the current basis still optimal?"
    - "If c₁ = 19/4 + ε, find the new optimal solution."
    - "c₃ = 2 + ε" 或 "c₃ = −ε"
  • 共同點：原基底不再最優（c̄ > 0），要從原基底繼續做 simplex。

2. 解題邏輯
  • 新增變數：B 與 b 沒變 → 原基底仍可行；只要算 c̄₀ = c₀ − y·a₀。〔L9 p57–60〕
  • c̄ > 0：讓那個變數進入，用 revised simplex（TOPIC 12）從原基底繼續做，通常一兩步就最優。
  • 這比從頭重解快得多（warm start）。

3. 解題 SOP
  Step 1　新增變數：c̄₀ = c₀ − y·a₀。
          c̄₀ ≤ 0 → 不生產，原解仍最優。
          c̄₀ > 0 → x₀ 進入。
  Step 2　d = B⁻¹aₖ（進入那一欄）。
  Step 3　Ratio test：只看 dᵢ > 0 的分量，t = min{ x_Bᵢ / dᵢ }，取最小者離開。
          全部 dᵢ ≤ 0 → unbounded。
  Step 4　更新：x_k = t，x_B ← x_B − t·d；J_B 中離開的位置換成 xₖ。
  Step 5　B⁻¹ 用 row operations 更新（以 d 的第 r 個分量為 pivot）。
  Step 6　新 y = c_Bᵀ B⁻¹，重算所有 c̄。全部 ≤ 0 → 最優；否則回 Step 2。
  Step 7　寫出新解、新最優值，以及（若有 c̄ = 0 的非基本變數）其他最優解。

4. 重要公式
  • c̄₀ = c₀ − y·a₀；y·a₀ = 損益兩平價格
  • d = B⁻¹aₖ；t = min{ x_Bᵢ / dᵢ : dᵢ > 0 }
  • ΔZ = c̄ₖ · t

5. 完整實戰案例（T10 Q10(d)，麵包店：新產品起司蛋糕）
  【題目】
    原問題同 TOPIC 21 補充案例，y = (0, 15, 15)，x_B* = (x₄, x₂, x₁) = (10, 6, 8)，Z* = 840
    新產品起司蛋糕：a₀ = (1, 1, 2)，c₀ = 50
  【辨識】新增變數 → TOPIC 23。
  【Step 1】y·a₀ = 0 + 15 + 30 = 45；c̄₀ = 50 − 45 = 5 > 0 → 值得生產，x₀ 進入
  【Step 2】d = B⁻¹a₀ = (1 − 7/4 + 1/2, 3/4 − 1/2, −1/2 + 1) = (−1/4, 1/4, 1/2)
  【Step 3】
    d₁ < 0 → 跳過
    x₂：6 / (1/4) = 24
    x₁：8 / (1/2) = 16 ← 最小
    → x₁ 離開，t = 16
  【Step 4】
    x₀ = 16
    x₄ = 10 + 16/4 = 14
    x₂ = 6 − 16/4 = 2
    J_B = {x₄, x₂, x₀}
  【Step 6】
    新 y = (0, 10, 20)
    c̄₁ = 60 − (10 + 60) = −10
    c̄₃ = 40 − (20 + 40) = −20
    c̄₅ = −10，c̄₆ = −20
    全部 ≤ 0 → 最優
  【答案】(x₁, x₂, x₃, x₀) = (0, 2, 0, 16)，利潤 920
  【驗證】ΔZ = c̄₀·t = 5·16 = 80 → 840 + 80 = 920 ✓；LP solver 920 ✓；
          新 y 的對偶目標 20·10 + 36·20 = 920 ✓
  【常見錯誤】ratio test 把 d₁ = −1/4 也算進去。
  【通用規則】新增變數只算一個 c̄；c̄ > 0 就從原基底做一次 revised simplex。

  補充案例 A（T10 Q6、Q8）
    y = (0, 0, 4)，a₀ = (−4, −3, 2)：y·a₀ = 8 → 原基底最優 ⇔ c₀ ≤ 8
    c₀ = 9：c̄₀ = 1 > 0，x₀ 進入
      d = (−4, 5, 2)，x_B = (14/3, 19/3, 2)
      ratio：(19/3)/5 = 19/15，2/2 = 1 ← x₄ 離開
      新解 (x₅, x₁, x₀) = (26/3, 4/3, 1)，y = (0, 0, 9/2)，最優值 9
      非基本變數 x₆ 的 c̄ = 0 → 還有其他最優解

  補充案例 B（T10 Q2：非基本係數剛超出範圍）
    c₁ = 19/4 + ε：c̄₁ = ε > 0，x₁ 進入
    d = B⁻¹a₁ = (3/2, 13/4, 1)，x_B = (1/2, 11/4, 2)
    ratio：(1/2)/(3/2) = 1/3 ← 最小，(11/4)/(13/4) = 11/13，2/1 = 2 → x₃ 離開
    新解 (x₁, x₄, x₇) = (1/3, 5/3, 5/3)
    新 y = (ε/3 + 1/4, 1/2, 0)，所有 c̄ ≤ 0 → 最優
    最優值 ε/3 + 13/4
    〔註〕PDF 文字層顯示為 3ε + 13/4，經直接計算與 LP solver 確認應為 ε/3 + 13/4。

  補充案例 C（T10 Q4：基本係數超出範圍，兩個方向）
    c₃ = 2 + ε：只有 c̄₆ = ε/4 > 0 → x₆ 進入
      d = (5/4, 1/2, −1/4)；ratio min{(19/4)/(5/4), (1/2)/(1/2)} = 1 → x₁ 離開
      新解 (x₅, x₆, x₃) = (7/2, 1, 1/2)，最優值 1 + ε/2（0 < ε < 1）
      〔註〕PDF 文字層顯示 2ε + 1，經驗算與 LP solver（ε = 0.1 → 1.05）確認為 1 + ε/2。
    c₃ = −ε：只有 c̄₇ = ε/2 > 0 → x₇ 進入
      d = (1/2, 0, 1/2)；ratio min{(19/4)/(1/2), (1/4)/(1/2)} = 1/2 → x₃ 離開
      新解 (x₅, x₁, x₇) = (9/2, 1/2, 1/2)，y = (0, 1/2, 0)，最優值 1/2

6. 常見錯誤與答案驗證
  • 驗證：ΔZ 應等於 c̄ₖ·t；新 y 的對偶目標 yᵀb 應等於新的 cᵀx。
  • 「值得生產」的判斷是 c̄₀ > 0，不是 c₀ > 0。

7. 考試速查
  • 一句話：算 c̄；c̄ > 0 就進入、做 ratio test、更新、再驗證最優。

附錄 A：相似題型辨識總表
==================================================

【A1】寫 dual：TOPIC 13 或 TOPIC 14？
  • max、全部 ≤、全部 x ≥ 0 → TOPIC 13（直接轉置）
  • 其他任何情況（=、≥、free、x ≤ 0、min）→ TOPIC 14（查表）

【A2】判斷最優：TOPIC 16 或 TOPIC 17 或 TOPIC 8？
  • 給一個數值解 x*，要求用 C.S. → TOPIC 16
  • 目標係數是符號，問「何時最優」→ TOPIC 17
  • 給一個 BFS 或 tableau，要求證明最優 → TOPIC 8（看 reduced cost）

【A3】係數範圍：TOPIC 17、20、21？
  • 有 B⁻¹，改的係數是非基本變數 → TOPIC 20（只看一個 c̄）
  • 有 B⁻¹，改的係數是基本變數 → TOPIC 21（y 變，全部重算）
  • 沒有 B⁻¹，所有係數都是參數 → TOPIC 17（C.S.）

【A4】Edges：TOPIC 4 或 TOPIC 6？
  • 給 CPF 的座標，在原變數空間找 → TOPIC 4（active constraints，n−1 條）
  • 給 BFS 或 basis，在 augmented 形式 → TOPIC 6（每個非基本變數一條 edge）

【A5】Simplex 版本：TOPIC 7、9、11、12？
  • 代數式寫出 z = v̄ + Σc̄x_N → TOPIC 7
  • 起始基底就是 slack，要求 tableau → TOPIC 9
  • 有 ≥ 或 = 約束，或 b < 0 → TOPIC 11（two-phase）
  • 要求 revised／matrix form，或給了 B⁻¹ → TOPIC 12

【A6】狀態判斷：TOPIC 2、8、19？
  • 二維、可畫圖 → TOPIC 2
  • simplex 中某進入欄 d ≤ 0 → TOPIC 8（unbounded 射線）
  • 要同時判斷 P 和 D，或要求 Farkas 證書 → TOPIC 19

【A7】Shadow price 與 b 的範圍
  • 改單一 bᵢ，問範圍或新最優值 → TOPIC 22
  • 改多個 b → TOPIC 22 Step 5，直接算 B⁻¹b_new
  • 問 y 是什麼 → TOPIC 18（y = c_Bᵀ B⁻¹）或 TOPIC 22

附錄 B：停止條件總表（max 問題）
==================================================

【B1】Simplex（代數、tableau、revised）
  • 最優：所有 c̄ⱼ ≤ 0（tableau 的 z 列存 −c̄，所以是 z 列全部 ≥ 0）
  • Unbounded：某 c̄ₖ > 0，而且 d = B⁻¹aₖ 全部 ≤ 0
  • 多重最優：最優時某非基本變數 c̄ⱼ = 0
  • 退化 pivot：ratio test 最小值 t = 0，目標值不變

【B2】Two-phase
  • Phase 1 結束：tableau 的 W 列全部 ≤ 0（沒有可進入的變數）
  • W* > 0 → 原 LP infeasible，停止
  • W* = 0 且 artificial 都不在基底 → 刪掉 artificial 欄，進 Phase 2
  • W* = 0 但 artificial 仍在基底（值為 0）→ 用退化 pivot 把它換出；若該列其他欄都是 0，該約束多餘，刪掉

【B3】C.S. 最優判斷
  • 主問題不可行 → 不是最優，停止
  • 解出的 y 唯一且對偶不可行 → 不是最優
  • y 對偶可行 → 最優，Z* = cᵀx* = bᵀy*

【B4】Sensitivity
  • 原基底仍最優 ⇔ B⁻¹b ≥ 0 且所有 c̄ ≤ 0
  • 某 c̄ > 0 → 從原基底繼續 simplex
  • 某 x_B 分量 < 0 → 原基底不可行（本課程到此為止，dual simplex 不在範圍內〔補充〕）

【B5】Tie-breaking（避免 cycling）
  • Bland's rule：進入取 c̄ > 0 中下標最小者；離開取 ratio 並列中下標最小者
  • Cycling 只會發生在退化 pivot 中
