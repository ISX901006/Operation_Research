記號：J_B 基本變數集合；B = J_B 各欄；y = c_Bᵀ B⁻¹；c̄ⱼ = cⱼ − y·aⱼ；d = B⁻¹aₖ；v = Aᵀy − c；s = b − Ax
全部以 max 問題為準。最優 ⇔ 所有 c̄ ≤ 0。

==================================================
PART I　建模與幾何
==================================================

T1 LP 建模
  辨識：文字題、資源、需求、比例。
  步驟：決策變數（含單位）→ 目標 → 每種資源／需求一條約束 → 非負。
  檢查：每條約束兩邊單位一致；比例條件寫成線性（x₁ ≥ 0.4(x₁+x₂) → 0.6x₁ − 0.4x₂ ≥ 0）。

T2 圖解法
  步驟：畫每條約束 → 找可行域 → 目標等值線往改善方向推。
  狀態：可行域空 → infeasible；沿改善方向無界 → unbounded；等值線與一邊重合 → multiple optima。
  答案寫最優點座標與 Z*；最優一定出現在某個 CPF（若有最優）。

T3 判斷 CPF
  步驟：代入檢查可行 → 列出 active constraints（含 x ≥ 0）→ 其係數矩陣的 rank = n ⇔ CPF。
  退化 CPF：active 的條數 > n。

T4 幾何 edges ★ FE Q2
  步驟：
    (1) 列出 x̄ 的 active constraints（含 xⱼ ≥ 0），共 p 條
    (2) 取 n−1 條保持 active（共 C(p, n−1) 種），解方向 d（滿足那 n−1 條等式的齊次方程）
    (3) 方向要讓剩下的 active constraints 仍滿足（否則不是 edge；兩個方向都試）
    (4) 沿 d 走到第一條變為 active 的 inactive 約束 → 端點（相鄰 CPF）；永遠不碰到 → 射線
    (5) cᵀd > 0 → improving edge
  FE Q2 答案：6 組配對、4 條真正 edge、1 條 improving，端點 (5/3, 2, 2/3)，Z = 32/3（也是最優）。
  易錯：漏了 x ≥ 0 的 active 約束。

==================================================
PART II　代數化與 simplex
==================================================

T5 Basis／BFS
  basis：m 個變數，B 可逆。BFS：x_B = B⁻¹b ≥ 0，非基本 = 0。
  退化 BFS：某 x_B 分量 = 0。
  Adjacent bases：恰好差一個變數。

T6 代數 edges
  每個非基本變數 xₖ 對應一條 edge：xₖ = t，x_B = x̄_B − t·d，其他非基本 = 0。
  t 的上限 = min{ x̄_Bᵢ / dᵢ : dᵢ > 0 }；d ≤ 0 → 射線。

T7 代數 simplex
  步驟：
    (1) 用非基本變數表示：z = v̄ + Σ c̄ⱼxⱼ
    (2) 全部 c̄ ≤ 0 → 最優，停止
    (3) 選 c̄ₖ > 0 的 xₖ 進入
    (4) Ratio test（MRT）：t = min{ x_Bᵢ / dᵢ : dᵢ > 0 }，取到最小者離開
    (5) Pivot，Δz = c̄ₖ·t，回 (1)

T8 證明最優／unbounded
  最優：寫出 z = v̄ + Σc̄ⱼxⱼ，c̄ ≤ 0 且 x ≥ 0 ⇒ z ≤ v̄，而 x̄ 達到 v̄。
  Unbounded：c̄ₖ > 0 且 d ≤ 0 → 射線 x(t) 對所有 t ≥ 0 可行，z = v̄ + c̄ₖt → ∞。

T9 Tableau
  z 列存 −c̄：最優 ⇔ z 列（變數欄）全部 ≥ 0。
  進入：z 列最負（LC 規則）；離開：最小比值（只看正的 pivot 欄）。
  Pivot：pivot 列除以 pivot 元素，其他列（含 z 列）消去該欄。
  退化 pivot：最小比值 = 0，z 不變。

T10 Tie-breaking
  LC：c̄ 最大者進入（tableau z 列最負）；受單位縮放影響。
  Smallest-subscript：c̄ > 0 中最小下標進入。
  LI：選讓 z 增加最多（c̄ₖ·tₖ 最大）的進入。
  Bland：進入取最小下標的 c̄ > 0；離開在平手中取最小下標。保證不 cycling。
  Cycling 只發生在一連串退化 pivot。

==================================================
PART III　Two-phase ★ FE Q3
==================================================

T11 Two-phase simplex
  辨識：有 ≥ 或 = 約束，或 b < 0（先乘 −1）。
  設定：
    ≤ → 加 slack
    ≥ → 減 surplus，加 artificial
    = → 加 artificial
  Phase 1：min W = Σ artificial。
    W 列 = 所有含 artificial 的列相加（消去 artificial 的係數）。
    進入：tableau 中 W 列為正的變數才能進入（常配合 Bland 取最小下標）。
  結束：
    W* > 0 → infeasible
    W* = 0 → 刪掉 artificial 欄；若 artificial 仍在基底（值 0），做退化 pivot 換出
  Phase 2：換回原目標，把基本變數代入 z 列消去，再跑 simplex。
  易錯：W 列沒有消去 artificial；Phase 2 的 z 列沒有代入基本變數。

PART IV　Revised simplex ★ FE Q4
==================================================

T12 Revised simplex（每一輪）
  (1) y = c_Bᵀ B⁻¹
  (2) c̄ⱼ = cⱼ − y·aⱼ（所有非基本變數）；全部 ≤ 0 → 最優
  (3) 選進入 xₖ（題目規則，常為 Bland）
  (4) d = B⁻¹aₖ；d ≤ 0 → unbounded
  (5) t = min{ x_Bᵢ / dᵢ : dᵢ > 0 }，離開第 r 個
  (6) x_B ← x_B − t·d，第 r 個位置換成 xₖ = t（J_B 原位替換）
  (7) B⁻¹ 更新：對 [B⁻¹ | d] 以 dᵣ 為 pivot 做 row operations
  驗證：B_new·B⁻¹_new = I；c_Bᵀx_B = yᵀb。

PART V　Duality
==================================================

T13 SIF dual ★ FE Q1(a)(i)
  (P) max cᵀx, Ax ≤ b, x ≥ 0 ⇒ (D) min bᵀy, Aᵀy ≥ c, y ≥ 0
  對偶約束 j 用 A 的第 j「欄」。
  FE Q1：min 4y₁ + 3y₂ + 5y₃，9y₁ + y₂ ≥ 2，y₁ + y₃ ≥ 2，y₂ + 2y₃ ≥ 4，y ≥ 0

T14 一般形式 dual
  (P) max：約束 ≤ / ≥ / = → y ≥ 0 / ≤ 0 / free
           變數 ≥0 / ≤0 / free → 對偶約束 ≥ / ≤ / =
  (P) min：約束 ≥ / ≤ / = → y ≥ 0 / ≤ 0 / free
           變數 ≥0 / ≤0 / free → 對偶約束 ≤ / ≥ / =
  檢查：拿一組可行解驗證 weak duality 方向。

T15 Weak duality 證明、C.S. 條件 ★ FE Q1(a)(ii)(iii)
  證明鏈：cᵀx ≤ (Aᵀy)ᵀx = yᵀ(Ax) ≤ yᵀb
    第一個 ≤：x ≥ 0 且 Aᵀy ≥ c
    等號：重新分組
    第二個 ≤：y ≥ 0 且 Ax ≤ b
  C.S.：sᵢ·yᵢ = 0（m 條），vⱼ·xⱼ = 0（n 條）
  恆等式：bᵀy − cᵀx = Σyᵢsᵢ + Σvⱼxⱼ

T16 C.S. 判斷最優 ★ FE Q1(a)(iv)
  (1) x* 主可行？標出 tight／slack
  (2) slack 的約束 → yᵢ = 0；xⱼ* > 0 → 對偶約束 j 取等號；解出 y*
  (3) y* ≥ 0 且其餘對偶約束都成立 → 最優；否則（y* 唯一）→ 不是最優
  FE Q1：x* = (4/9, 0, 5/2)，s₂ = 1/18 → y₂ = 0；y* = (2/9, 0, 2)；y₁ + y₃ = 20/9 ≥ 2 ✓ → 最優，Z* = 98/9
  非最優改進：yᵢ < 0 → 解 Ad = −eᵢ（其他 tight 保持），沿 d 走到某變數為 0。

T17 參數化目標 ★ FE Q1(b)
  同 T16，但用 c 表示 y，再要求對偶可行。
  FE Q1(b)：y = (2c₂ − c₁, c₁ − c₂)；答案 c₂ ≤ c₁ ≤ 2c₂ 且 c₃ ≤ 2c₂ − c₁
  易錯：漏了 x̄ⱼ = 0 那條對偶約束（c₃ 的條件）。

T18 Complementary basis
  配對：xⱼ ↔ vⱼ，sᵢ ↔ yᵢ
  K_N = 和主問題「非基本」變數配對的對偶變數
  y = c_Bᵀ B⁻¹；c̄ⱼ = −vⱼ；c̄_sᵢ = −yᵢ
  兩邊目標值恆相等；主問題最優 ⇔ 對偶可行；兩邊都可行 ⇔ 兩邊都最優

T19 Primal–dual 狀態、Farkas
  可能組合：(最優, 最優)、(不可行, 不可行)、(不可行, 無界)、(無界, 不可行)
  P 無界 ⇒ D 不可行；P 不可行 ⇒ D 不可行或無界
  Farkas：Ax = b, x ≥ 0 無解 ⇔ ∃y：Aᵀy ≥ 0，bᵀy < 0（y free）
          Ax ≤ b, x ≥ 0 無解 ⇔ ∃l ≥ 0：Aᵀl ≥ 0，bᵀl < 0
  每個判斷都附證據：射線、矛盾組合、或證書。

PART VI　Sensitivity
==================================================

原基底仍最優 ⇔ B⁻¹b ≥ 0 且所有 c̄ ≤ 0

T20 非基本變數 cⱼ
  只有 c̄ⱼ 變：cⱼ ≤ y·aⱼ。範圍內 x*、Z* 都不變。

T21 基本變數 cₖ
  y(cₖ) = c_Bᵀ B⁻¹（cₖ 為符號）→ 所有非基本 c̄（含 slack：c̄_sᵢ = −yᵢ）重算 → 取交集
  範圍內：x* 不變，Z* = Z_old + Δcₖ·xₖ*
  檢查：代入原 cₖ 應得到原 y。

T22 右端 b
  x_B(bᵢ) = B⁻¹b ≥ 0（= x_B* + Δbᵢ·B⁻¹ 第 i 欄）
  範圍內：ΔZ = yᵢΔbᵢ；slack 在基底中 → yᵢ = 0
  買資源：單價 < yᵢ 才買，最多買到範圍上界。
  多個 b 同時改：直接算 B⁻¹b_new，個別在範圍內不代表一起可行。

T23 新增變數、超出範圍
  c̄₀ = c₀ − y·a₀；c̄₀ > 0 → x₀ 進入
  d = B⁻¹aₖ → ratio test → 更新 → 新 y → 重算 c̄ → 全部 ≤ 0 即最優
  檢查：ΔZ = c̄ₖ·t；新 cᵀx = 新 yᵀb
  某 c̄ = 0 的非基本變數 → 有其他最優解

==================================================
停止條件
==================================================
  最優：所有 c̄ ≤ 0（tableau z 列 ≥ 0）
  Unbounded：c̄ₖ > 0 且 d ≤ 0
  多重最優：最優時某非基本 c̄ = 0
  Infeasible：Phase 1 的 W* > 0
  退化 pivot：t = 0，z 不變；Bland 防 cycling
  C.S.：主不可行，或唯一 y 對偶不可行 → 不是最優

==================================================
十大易錯
==================================================
  1. FE 型 edge 題漏了 x ≥ 0 的 active 約束
  2. Ratio test 把 dᵢ ≤ 0 也算進去
  3. Tableau z 列存的是 −c̄，最優條件方向搞反
  4. Two-phase 的 W 列沒消去 artificial；Phase 2 z 列沒代入
  5. 寫 dual 忘了轉置；min 問題用了 max 的對照表
  6. C.S. 漏檢 xⱼ = 0 對應的那條對偶約束
  7. K_N 用主問題的「基本」變數配對（應為非基本）
  8. 基本變數係數改變時只檢查部分 c̄，漏掉 slack
  9. 改 b 時用 B⁻¹ 的「列」（應為欄）；超出範圍仍用 shadow price
  10. 「值得生產」看 c₀ > 0（應看 c̄₀ > 0）
